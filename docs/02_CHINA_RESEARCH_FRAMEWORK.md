# 中国地名历史研究框架 v0.1

本稿为研究提纲，不是已完成的通史。

## 六个历史观察层

| 观察时段 | 首先研究的机制 | 首批证据类型 |
|---|---|---|
| 商周与先秦 | 聚落、方国、族名与人地同名；名称跨对象转移 | 甲骨文、金文、先秦传世文献 |
| 秦汉 | 郡县制下行政名称规范、旧国与旧邑承继 | 地理志、出土简牍、历史行政资料 |
| 魏晋南北朝 | 人口迁徙、侨州郡县、同名异地与政区分合 | 正史地理志、侨置政区研究 |
| 隋唐宋 | 州郡县调整、旧名拆取与继承、舆地学积累 | 地理志、舆地总志、地方史 |
| 元明清 | 多语接触、音译/意译、民族聚居区地名与政区变动 | 多语文献、地方志、舆图 |
| 近现代 | 政区标准化、重复县名更改、现代地名法规与历史文化保护 | 法规、公报、地名志、行政区划变更公告 |

该分期按研究机制组织，不表示各时期的机制彼此排斥；不把族群、语言接触或政治命名局限在某一朝代。

## 四条彼此分开的历史线

1. **名称史**：名称形成假说、最早可证文字、别名、音形。
2. **地域史**：名称指向的具体地点、疆域、实体边界与地望争议。
3. **建置史**：行政设置、级别、隶属、治所、裁撤与复置。
4. **语义史**：普通词义、专名义、跨语言词义、语义透明度与转化。

## 六个不能混淆的问题

- “某地何时设置行政区”不等于“这个名称何时诞生”。
- “地名中的字有古义”不等于“整个地名原始词义已证”。
- “发音相近”不等于“确定属于同一语言词源”。
- “地方志中的传说”不等于“同时代的形成证据”。
- “今天名称相同”不等于“历史联系已证”。
- “行政区边界改变”不等于“地名一定改变”。

## 首批重点历史问题

- 邯郸、郴州等地名用字是否长期趋于专用？
- 朝阳的普通词义与不同地域命名史如何并存？
- 杭州直接从余杭取字的历史过程与“余杭”更早词源如何区分？
- 上海名称是否先指河流、聚落或其他对象？证据何在？
- 鄂尔多斯的蒙古语原义、部族与区域名称在各时期如何关联？
- 敦煌起源存在什么竞争假说，它们分别依靠哪些材料？

各问均待逐案建立来源卡，现阶段不得从问题本身推出答案。

## P1-B 实证节点：秦汉郡县改变地名的制度角色

秦以前同名族国与居地需检验词源方向；秦汉则出现从“某地有某名”到“某行政层级把此名写进通用公文”的可观察变化。
- 把旧地域名称纳入郡县行政体系，不等于把旧名全部废弃；
- 同一名称可以在不同政权的行政组织下继续存在（如迁陵），并不等于边界不变；
- 上级政区（秦洞庭、汉武陵）可以改变，而部分属县名仍可保留，两个郡是否一对一直接更名要独立核；
- 实际地名在邮书、赋税、户籍、司法、吏员调动中成为行政通讯键（里耶简）；
- 汉初“新丰”体现移民记忆与人为仿建命名（应劭为后代释源）；新莽“无锡→有锡”体现政治字义改造而非自然地理变化。

本期个案 [P1B研究札记01](research/P1B_01_QIN_HAN_TOPONYM_STANDARDIZATION.md)，明确材料与结论层级。

## P1-B 第二轮新增：山川名→政区名，词义与地望应当独立

河流在不同历史时代可能同时是自然地理参照、区域描述、郡县名称和政治身份的语言来源。以黄河（河东、河南、河内）、汉水（汉中、汉王、汉朝）为例，分别观察：
1. 自然参照对象和方位；
2. 具体行政实体名称采用的时间；
3. 同名词语在其他地望独立使用的可能；
4. 原名/新名在不同时间段的行政边界；
5. 名称从空间转向政治称号的历史证据；
6. 文字、地理指称、行政身份与社会身份的分离。

**反例**：简456梁县与《汉书·地理志》河南郡梁县被2025年学者认为异地同名；卷县迁治衡雍可能造成后世误认古县址。两者尚未由本仓库独立核原简，列为压力测试。

详见[札记02](research/P1B_02_RIVER_NAMES_ADMINISTRATIVE_REANCHORING.md)。

## P1-B 第三轮：地名的“存续”应按用途分轨

地名不能只被归类为“沿用/消失/恢复”。同一词形可能分别在行政县、郡国、市、山川、文化著述、地方称谓和现代采名中不同步存续。

邯郸：市级名称持续，而2016县级主体撤销；汉书赵国桓亭须读清郡国层级。  
无锡：古籍记王莽改有锡，复名历史与古越语/矿产词源分别研究。  
姑苏：文化古名长期保留，2012纳入新设现代行政区专名，并被2014自然地理保护名录和2016历史采词制度进一步体现。  
会稽：旧县名曾终止，1914道级名复用，1949—1950新设会稽县短期使用，自然山名继续保存。

详见 [P1-B生命史札记03](research/P1B_03_TOPONYM_LIFECYCLE_AND_REUSE.md)、[生命周期协议](methods/TOPONYM_LIFECYCLE_PROTOCOL.md)。

## P1-D v1.2 唐宋市镇商业地名：名称在多种社会机构的扩展

在隋唐州郡行政通名改革之外，宋元城市命名可能存在由税务、贸易、港口市镇促进旧名被反复使用，再纳入正式县名的机制。

上海：上海浦/上海务/上海镇/上海县分别是水道、榷酒、商业聚落和县级行政组织；先后与原始命名动机不完全可证。青龙镇作为曾经繁荣的唐宋港口，在后来的现代行政城市主名中并未胜出，但名称保留在考古和文化遗产渠道。

研究必须加一个“商业/财政名称”维度和原始史料层级区分：
- 河流/沟浦名称和聚落名称是否独立、何者先出现；
- 酒务、税课、巡检、市舶、镇等机构的名称使用和建置时点；
- 市镇商业功能的兴衰不必等于行政区名存续的同一节律；
- 正式县级命名存在建议、批准、落实和后代追述时间差（上海1290/1291/1292）；
- 经济活跃为地名升级的充分、必要条件均需跨案例反证，不可因上海最后成为大都市倒置原因。
