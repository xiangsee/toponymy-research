# 中国地名历史研究框架 v0.1

本稿为研究提纲，不是已完成的通史。

## 六个历史观察层

| 观察时段 | 首先研究的机制 | 首批证据类型 |
|---|---|---|
| 商周与先秦 | 聚落、方国、族名与人地同名；名称跨对象转移 | 甲骨文、金文、先秦传世文献 |
| 秦汉 | 郡县制下行政名称规范、旧国与旧邑承继 | 地理志、出土简牍、历史行政资料 |
| 魏晋南北朝 | 人口迁徙、侨州郡县、同名异地与政区分合 | 正史地理志、侨置政区研究 |
| 隋唐宋 | 州郡县调整、旧名拆取与继承、舆地学积累 | 地理志、舆地总志、地方史 |
| 元明清 | 多语接触、音译/意译、民族聚居区地名与政区变动 | 多语文献、地方志、舆图 |
| 近现代 | 政区标准化、重复县名更改、现代地名法规与历史文化保护 | 法规、公报、地名志、行政区划变更公告 |

该分期按研究机制组织，不表示各时期的机制彼此排斥；不把族群、语言接触或政治命名局限在某一朝代。

## 四条彼此分开的历史线

1. **名称史**：名称形成假说、最早可证文字、别名、音形。
2. **地域史**：名称指向的具体地点、疆域、实体边界与地望争议。
3. **建置史**：行政设置、级别、隶属、治所、裁撤与复置。
4. **语义史**：普通词义、专名义、跨语言词义、语义透明度与转化。

## 六个不能混淆的问题

- “某地何时设置行政区”不等于“这个名称何时诞生”。
- “地名中的字有古义”不等于“整个地名原始词义已证”。
- “发音相近”不等于“确定属于同一语言词源”。
- “地方志中的传说”不等于“同时代的形成证据”。
- “今天名称相同”不等于“历史联系已证”。
- “行政区边界改变”不等于“地名一定改变”。

## 首批重点历史问题

- 邯郸、郴州等地名用字是否长期趋于专用？
- 朝阳的普通词义与不同地域命名史如何并存？
- 杭州直接从余杭取字的历史过程与“余杭”更早词源如何区分？
- 上海名称是否先指河流、聚落或其他对象？证据何在？
- 鄂尔多斯的蒙古语原义、部族与区域名称在各时期如何关联？
- 敦煌起源存在什么竞争假说，它们分别依靠哪些材料？

各问均待逐案建立来源卡，现阶段不得从问题本身推出答案。

## P1-B 实证节点：秦汉郡县改变地名的制度角色

秦以前同名族国与居地需检验词源方向；秦汉则出现从“某地有某名”到“某行政层级把此名写进通用公文”的可观察变化。
- 把旧地域名称纳入郡县行政体系，不等于把旧名全部废弃；
- 同一名称可以在不同政权的行政组织下继续存在（如迁陵），并不等于边界不变；
- 上级政区（秦洞庭、汉武陵）可以改变，而部分属县名仍可保留，两个郡是否一对一直接更名要独立核；
- 实际地名在邮书、赋税、户籍、司法、吏员调动中成为行政通讯键（里耶简）；
- 汉初“新丰”体现移民记忆与人为仿建命名（应劭为后代释源）；新莽“无锡→有锡”体现政治字义改造而非自然地理变化。

## P1-B 第二轮新增：山川名→政区名，词义与地望应当独立

河流在不同历史时代可能同时是自然地理参照、区域描述、郡县名称和政治身份的语言来源。以黄河（河东、河南、河内）、汉水（汉中、汉王、汉朝）为例，分别观察：
1. 自然参照对象和方位；
2. 具体行政实体名称采用的时间；
3. 同名词语在其他地望独立使用的可能；
4. 原名/新名在不同时间段的行政边界；
5. 名称从空间转向政治称号的历史证据；
6. 文字、地理指称、行政身份与社会身份的分离。

**反例**：简456梁县与《汉书·地理志》河南郡梁县被2025年学者认为异地同名；卷县迁治衡雍可能造成后世误认古县址。两者尚未由本仓库独立核原简，列为压力测试。
