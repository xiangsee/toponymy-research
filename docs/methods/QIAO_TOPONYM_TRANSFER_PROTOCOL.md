# 侨州郡县名称迁移与土断核验协议 v0.1

## 对象须分别建实体
- 原籍实体 original_referent_id：北方原州郡县及其时代/辖域；
- 侨置实体 qiao_admin_id：南方迁入地新设的同名行政单位；
- 当地已有实土政区 local_admin_id：迁入人口实际居住区域；
- 侨民/侨籍 migrant_register_id：有迁移、籍贯和户籍证据的人群；
- 户籍/土断事件 tuduan_event_id：事件所影响的人口、机构和地域；
- 后期实土行政实体 territorial_successor_id：有证据时另建，不用名字相同直接等同。

## 核查顺序
古籍原文→迁出原籍与侨置名称→侨流人口证据→侨官署是否设置→是否无实土→土断事件具体范围→是否割实或撤并→后续所指地理对象与名称社会存续。

## 不得混同
侨州郡县≠普通民间迁民聚落名称；侨郡≠遥领、虚封（需要核实权力与人口）；土断≠全部侨郡当日废除；家族祖籍/郡望≠现居和官署郡治；名号相同≠行政对象及边界相同。

## 证据等级
CLASSICAL_TEXT_READ、OFFICIAL_PROJECT_SUMMARY、JOURNAL_ABSTRACT、CHGIS_RECONSTRUCTION、ORIGINAL_EDICT_VERIFIED等分别标注。最早侨置年份、郡治地点、改制时点只在有对应史料时提升证据等级。

## 出版与反证
对照人口迁徙规模的不同估计、南北同名并存、土断后侨置保存的反例、隋统一后仍长期存在的旧名。未经合法授权不上传古籍整理高清图或现代专著全文。
