# 地名多轨生命史核验协议 v0.1

> 适用于《详见》中国地名史 P1-B 及后续历史地名的数据积累；不直接用来判断商标注册资格。2026-11-21。

## 一、与普通更名年表的区别

一个名称没有一个独立于对象和场景的“存活/死亡”布尔变量。

记录单位为 `(name_form, referent_id, use_channel, time_scope, evidence_status)`。

- `name_form`：实际汉字/异体/其他语言写法。
- `referent_id`：那个具体历史对象：某县、某郡国、某城址、某山、某文化名称或后来新设的行政实体。
- `use_channel`：行政（必须说明级别）、自然地理、民间、文化、志书、制度保护。
- `time_scope`：最早存世记载、实行日期、推定时段、失去某项使用地位的时期。
- `source_level`：原始文书/传世古籍/现代地理重建/后代释源/检索摘要。
- `evidence_status`：已证 / 文献转述 / 模型推定 / 学术假说 / 无证。

**“某县撤销”仅说明某县级实体终止，不说明整词在别处全部消亡。**

## 二、必须拆开的事件类型

| 事件 | 含义 | 示例 | 不等价的概念 |
|---|---|---|---|
| `ADMIN_TERMINATED` | 特定县级/郡级行政实体撤销 | 邯郸县2016年撤销 | “邯郸”字符串消失 |
| `POLITICAL_RENAME` | 同一行政层级更名 | 王莽赵国“桓亭” | 邯郸县一定改名桓亭 |
| `RESTORATION_IN_LATER_PERIOD` | 原名后来重新用于前后相关行政实体 | 无锡/有锡/无锡 | 恢复时点和古代词源均已证 |
| `CULTURAL_ALIAS_ADOPTED_FOR_NEW_ADMIN_ENTITY` | 古别称用于新行政单位 | 2012姑苏区 | 古代同级单位复置 |
| `CROSS_LEVEL_NAME_REUSE` | 同名出现于不同层级 | 会稽县/会稽道 | 上级和县级是同一个行政实体 |
| `REESTABLISHED_NAME_NEW_ENTITY` | 历史旧县名用于新设县 | 1949会稽县 | 两县边界、机构、人口完全同一 |
| `GEOGRAPHIC_NAME_CONTINUES` | 自然地理名仍在使用 | 会稽山、姑苏山 | 旧县必未撤销 |
| `URBAN_NAME_WITH_LOCATION_CHANGE` | 同名城市的城址/形态改变 | 邯郸 | 原城墙和城址不变 |

状态不得直接跨层级传播。例如 `ADMIN_TERMINATED` 不影响 `CULTURAL_NAME_ATTESTED` 的时间区间。

## 三、手工审查三道关

1. **文献作用域**：古籍“莽曰桓亭”到底放在“赵国”条还是“邯郸县”条？先读清语法和条目归属。
2. **历史对象同一性**：1911之前会稽县与1949新会稽县是否具有完全一样的县治、边界和行政机构？名称一样不等于原主体仍在。
3. **证据时间归属**：一份地方年鉴说1911合县，另一份记1912；是命令发布还是生效？CHGIS公元23年恢复无锡是原始文书还是时序模型？

## 四、负向验证和选择偏差

研究中尤其要记录这些反例：
- 旧县改名后新名持续使用，旧名只作为古迹/文化名称。
- 原名再被采用，但新行政单位等级或地域范围显著不同。
- 名称不变，实际所指城市迁移、县界分割或行政组织撤销。
- 地方宣传说“千年不改名”，古籍却有不同级别短期更名；两者必须分层而非简单判谁虚假。
- 古代普通词或古越语记音说法并存，后来的解释不能冒充最初命名原因。

选取成功存续的四个案例不能估计“中国多少地名可存续千年”。必须找到全部曾存在的政区名，包括后世消失且不常见的名称作为分母；避免文献保存偏差与幸存者偏差。

## 五、与此前证据治理的对接

所有关键断言附来源ID、`affected_claim`、`impact_type`、`verification_next`。

本轮代表性改正：
- `affected_claim`: “王莽把邯郸县改为桓亭县”（二手叙述待证，非本项目既定事实）
- `impact_type`: 对仅凭《汉书》赵国条证明这一说法的用法提出**反证/修正**
- `verification_next`: 继续找独立县级更名文书或实物；没有就保持未证。
- `affected_claim`: “同名重新出现=同级行政主体恢复”
- `impact_type`: 反例拆分为姑苏别称采名、会稽不同层级复用及1949另设新县。
- `verification_next`: 查每项设县/撤县批文及真实疆域。
