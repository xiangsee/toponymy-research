# 地名史料“作者—传本—事件时间”三层审计协议 v0.1

**2026-11-25｜《详见》P1中国地名史**。因嘉定县建置年代与四川嘉定府词源考证而提出。只用于历史证据，不用于预判法律或商标规范。

## 一、按四个时间标签核“首次设立”声明

1. `event_time`：行政行为本身（奏请、批准、官署到任、开始运行），一个事件不得自动合成单一建置“生日”。
2. `authorial_composition_time`：作者何年写、是否本人亲历（高衍孙《创县记》自署1220）。
3. `witness_copy_time`：现存可读具体文本何时被传抄、刻入地方志或文集（《吴郡志》1229补注、明钱榖文集、康熙嘉定县志、现代CHGIS转录）。
4. `later_historical_compilation_time`：后出《宋史·地理志》或清代考据所载年份。

**核心规则**：事件1222首次成立若同署1220的当事人在创县记中已说明1218主持县务构成不可忽视的时间反证；应修正证据等级，但文本本身仍须早本校勘。

## 二、书名作者不等于该条的作者

宋范成大卒1193，《吴郡志》原稿止1192；嘉定1217建县条为1229筹刊时汪泰亨等后补注。故下面的标签必须同时存在：
- `work_title = 吴郡志`
- `original_author = 范成大`
- `specific_entry_author_or_editor = 汪泰亨等补注`
- `original_recorded_event = 嘉定十年奏请`
- `present_witness = 四库/现代电子版`

对于明《吴都文粹续集》和康熙《嘉定县志》所存高衍孙1220同一原作，`provenance_family = PROV-JD-GAO-1220`，不得算为两次独立亲历观测。

## 三、古地名数据表不可只存一项“founding_year”

必须存：
- `candidate_founding_event`（例如宋嘉定十年秋九月奏议、冬十二月准奏）；
- `earliest_office_functioning`（戊寅五月高衍孙自述在任）；
- `original_witness_text` 和 `original_text_date`（1220署名）；
- `later_record_mentioned_year`（宋史嘉定十五年1222）；
- `scholarly_preferred_date` 与说明支持其依据；
- `unresolved_version_conflict`（为什么宋史误五年仍未解释）；
- `comparison_of_subdivisions`（五乡二十八都 vs 五乡二十八保；不能因数相同视为同一单位）。

## 四、证据与行政效果分开

《省札》描述昆山东部的诉讼、治安及赋税困难，是官员为争取设县所提出的政策理由；高衍孙《创县记》写其宽恤、免耗、营造和居民反应，属于任官者的自我叙述。两者证明**当时官员主张与措施设计**，不自动证明客观犯罪/赋税水平或实际政策成效。后者需要独立税籍、案件、人口以及其他人叙事。

## 五、对历史词源负例进行“年代排除+古人考证”双测试

四川嘉定府1195《宋史》本纪或1196地志所记均早于嘉定年号1208，故不能据字形同名判由1208年号命名。对初名还应查：
1. 宋代庆元当年升府批准和选名字的原文；
2. 原“嘉州”的嘉字是否被借取、与“定”的组合何时第一次明确解释；
3. 清钱大昕《十驾斋养新录》数字本差异（有无“蜀之嘉定府非因年”的字句）；
4. 明郭子章《郡县释名》批“汉成帝古磬改嘉定、光武嘉州”等不可信释源；
5. 古代学者对某一来源提出反证，属于**解释史证据**，不是宋朝最早命名令。

## 六、数据约束

- `source_ids` 必须存在来源目录；`case_id` 必须指已存在个案；
- `witness_id` 唯一；同一来源原作的不同传本必须共享 `provenance_family`；
- `source_review_level` 必须标明其是否**作者原作后代传本**、**官府原文后出抄件**、**古籍后编**、**现代学术论断**、**索引检索或OCR**；
- 不强制“历史上所有事”只有一个年份，也不能无证把1195本纪定为审批、1196地志定为实施；
- 将新反证接入Claim Lifecycle：`affected_claim`、`impact_type`、`verification_next`。
