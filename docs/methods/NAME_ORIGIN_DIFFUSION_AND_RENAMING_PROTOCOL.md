# 地名形成、经济传播与政治再命名分离协议 v0.1

**研究位置**：《详见》中国地名史 P1-D，2026-11-22。用于“上海、青龙镇、景德镇、明州/宁波”等跨行政/市场/产业数据，不等同于商标法、品牌价值或行政区划现行规范。

## 一、三类不同的研究命题

### A. 名称从哪里来？（ORIGIN）
- 原始名称形式（包括古文字、音译、字词组合）、首次可证使用时间、词源及竞争解释。
- 必须区别**同一名称最早文字记载**、**首次设行政单位**、**最初词源的后出解释**、**原始命名令**。
- 例如明州取“四明山”在《旧唐书》《新唐书》明确，为**后出正史记述山名来源**；738年齐澣奏请原件另待查。
- 景德镇“景德年间以年号命镇”有清代《陶录》和现行官方历史叙述，**宋真宗原始亲赐名诏令尚未找见**；不能把一个传说性的具体因果说成已核档案。

### B. 名字怎样广泛传播？（DIFFUSION）
- 商品生产销售、港口贸易、税务/榷酒、市舶机构、族谱迁徙、交通网络、文化记忆等可以扩展名称传播范围。
- **传播机制不等于命名机制**。景德镇产品名声大不证明“景德年制”底款创造镇名；明州宋代港务发达不证明唐738年是因为宋代港务才名明州。
- 传播命题要有不同年代的文献、交易数据与社会用语，最好有贸易规模变化的负样本（青龙镇），否则标 hypothesis。

### C. 国家为何再次改变名称？（RENAME）
- 正式州、郡、镇、县、府、市的行政层级变化和名称改动；
- 年号、皇帝潜藩、国号避讳、政治评价和原有自然地理名称均可能参与。
- 例：“明州→余姚郡→明州”是唐742/758州郡调整；“明州→庆元府”1194年十一月升府见《宋史·宁宗本纪》，1195是新年号开始；“明州府→宁波府”1381年二月见《明史》。
- 各事件须分别保存：文献记载年份、正式批准时间、官署运行时间、传统通行纪年、史料形成时间。**不因现代地方史采用某年就删除其他古籍异文。**

## 二、对后代解释的反证核验

- 古代书籍在晚出时代可能把自己的商品款识制度投射到更早朝代。2025吴红云、邵建春《北宋“景德年制”瓷器款识新考》摘要正针对清代以明永乐帝王纪年款倒推宋朝提出批评。需独立核湖田窑发掘报告和论文全文。
- “景德年制”未见可靠实物的专业论断与“景德镇用景德年号命名”是不同的断言。否定前者并不必然否定后者，更不自动证明亲赐诏令存在。
- 明代关于“海定则波宁”的宁波命名故事，仍要与明史1381年二月改名公文分开。
- 《宋史》1194升庆元府与地方沿革习用1195庆元元年是不同时间标签，不能投票或取平均。

## 三、事件最小字段

`event_id`; `case_id`; `name_form`; `historical_object_type`; `time_scope`; `time_basis`; `event_type`; `source_ids`; `evidence_status`; `supported_statement`; `not_established`; `verification_next`。

每条重要研究判断另记 `affected_claim`、`impact_type`（supports/revises/refutes/extends）、`verification_next`。并严格按 source type 列出：
- PERIOD_CONTEMPORANEOUS_DOCUMENT；
- LATER_DYNASTIC_HISTORY；
- LATE_GAZETTEER_ETYMOGRAPHY；
- MUSEUM_ARCHAEOLOGY_WITH_OBJECT_ID；
- MODERN_JOURNAL_ABSTRACT_ONLY；
- MODERN_GOVERNMENT_HISTORY；
- INTERPRETIVE_HYPOTHESIS。

文献越晚不是必然错误，但该来源不会自动变成同期事实。

## 四、两项必须留在库内的反证

1. **产业名声不能确保成为行政名**：青龙镇唐宋重要外贸港，仍未成为现代“上海市”主名。还有别的港市需要继续抽样。
2. **政治名称不必与商品产业命名同步**：明州先据山名设州（738），港贸制度在宋992/999强化，1194/1195和1381又由政治性因素改名。

## 五、阶段约束

P1中国地名史持续推进，P2世界地名比较与P3地名商标制度史均不得提前代入制度判断。尤其不要直接把现代“地方品牌”“产地商标”的规范含义倒推宋唐产业地名史。
