# 年号地名：同名性、行政建置与词源方向核验协议 v0.1

**《详见》中国地名史 P1-D**｜2026-11-22。仅用于历史地名研究，不直接推导现行商标注册规则。

## 一、先对研究问题做五层拆解

1. **词形与年号识别**：某名称汉字与某一帝王年号恰好相同吗？必须有该年号的真实起讫时段。
2. **最早可证名称使用**：历史地名首次可复核记载出现在哪本书、何时成书、记载的是哪一年、何种空间对象？
3. **行政建置事实**：旧州升府？既有县析乡设县？镇直接升县？旧郡改专名？必须避免把年号仅作为一件另起行政事件的“时间标签”。
4. **建置理由与名称选择**：发生行政调整的动机（司法、税役、治理距离、皇帝潜邸/封号）与名字为什么选该年号（令文、奏请、后人释源）分别建两个关系。
5. **来源和异文审查**：本纪、地理志、同时代请命/诏书、明清县志、当代政务简介、历史GIS建模不等价；即使都写同一名字，史源日期与结论可相互矛盾。

## 二、年号词源检验门槛

- `same_form_as_era` 并不自动代表 `derived_from_reign_name`。
- **硬性反例**：四川嘉定府在宋宁宗嘉定年号（1208年开始）之前就已见于庆元元年1195本纪/庆元二年1196地志，**该嘉定府不可能由尚未出现的1208年嘉定年号造成**。
- `earliest_name_date < era_begin_date` → 将“来源于该年号”的方向标为 `CHRONOLOGICALLY_EXCLUDED`，但不推断真实词源已证。
- `earliest_name_date >= era_begin_date` → 只能得到 `CHRONOLOGICALLY_POSSIBLE`；仍需要当年设名文书或明言年号来源的可靠史料。
- 古籍有“以年为名”“以年号名县” → `DOCUMENTED_LATER_REPORT_OF_ERA_ORIGIN`；要再问是同时代书面令文还是后出史家描述。
- “皇帝年号”选择理由与政治心理（祈愿祥瑞、镇压地方等）是不同断言，不能从字面构造皇帝当场心理。
- **不要把“嘉定府”的“嘉定”自动指向“上海嘉定县”**：`referent_id` 与 `historical_admin_level` 独立；同字可能是另一处同形名。

## 四、证据类型和数据方法

### 时间字段
- `reign_era_start`: 年号开始；
- `year_as_chinese_era`: 古代纪年；
- `gregorian_date`: 公历折算（须识别跨年）；
- `administrative_proposal_date`: 地方上奏；
- `decision_date`: 中央批准；
- `implementation_date`: 官署实际运行；
- `source_written_at`: 史料自身编纂年代；
- `source_status`: 同时代诏令、后代本纪、后代地理志、明清志书、现代校注、GIS和媒体转引。

### 异文与冲突
- **嘉定县**：嘉定十年1217（农历十二月折公历1218）与嘉定十五年1222，属于**五年史源分歧**，不等于历法换算；尚未查到完整原省札。
- **嘉定府**：宋史本纪庆元元年1195升府与宋史地理志庆元二年1196，不能没有原令便推断“本纪批准—地志实施”已证。
- **嘉定县都数**：官方/现代研究分记五乡27/28都，不能凭哪一方权威较高就删另一项；需要当时原分割册。
- **淳化旧镇文字**：宋史传本文字“黎国”与宋长安志“梨园/黎园”，清洪亮吉校为刻误；不能把误字直接建为独立镇名。
- **淳化四年公历**：现代旧志校注括注“994”，与淳化四年993不同；来源状态仅PDF文本可读、截图超时，严守校本核验缺口。

## 五、研究交付及CI约束

- 每一条语料、命名行为、政府建制行为独立编号，引用至少一项 source_id；
- 每一条源间冲突双边保留 `source_a_ids`、`source_b_ids`、`why_not_resolved`、`verification_next`；
- 不允许将 `CHRONOLOGICAL_NEGATIVE_CONTROL` 错标为“年号已证来源”，数据校验对此有约束；
- 所有 Claim Lifecycle 用 `affected_claim`、`impact_type`、`verification_next` 明示更新，不能把找不到证据说成已证明不存在；
- 正文注明行政级别、原历史地望和现今参考地点的区别。
