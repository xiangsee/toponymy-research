# 研究顺序与阶段门

## P1 中国地名史｜ACTIVE
目标：建立中国地名形成、词义变化和地域/政区演变的可靠分类与案例基线。
- P1-A 文献谱系：先秦甲骨金文、秦汉地理志、历史地理著作、政区史、地名学史。
- P1-B 起源机制：自然环境、聚落生活、族群、古国、行政权力、文化典故、旧名继承、语言接触。
- P1-C 词义史：普通词→地名；专名化；古义隐没；音译字形与原语义；地名派生社会称谓。
- P1-D 事件史：命名/更名/复名/承继/迁移/分合/治所变动/书写与语音改变。
- P1-E 案例与反证：按地区、时期、语言类型抽样，审查分类例外。
- P1-F 阶段验收：资料可追溯、反例已测试、未知比例被如实报告、分类版本可解释。

**不得以个案数替代核验质量**；初始案例是检索任务而非完成的词源鉴定。

## P2 世界地名比较｜PLANNED / NOT STARTED
前置条件：P1有可比较的数据结构与最低核验基线。
后续独立研究各语言和历史传统的地名来源，考虑古典语言、移民命名、殖民历史、宗教和国家治理。比较前不预断“不同或相同”程度。

## P3 商标地名制度史｜PLANNED / NOT STARTED
前置条件：P1与P2的比较事实与方法论经过复盘。
届时追溯法律规则的最初成文来源、不同法域变体、条款移植与中国立法历程，逐项检验历史理由是否变化。
本阶段**不开展规范结论**，避免目的论倒推。

## 依赖与出口

P1 → 经阶段复盘及来源审计 → P2 → 完成比较证据审计 → P3。

所有研究过程可以公开记录，但未经阶段审核不宣称已经完成。
