# P1-D 札记03｜产业与港口能传播地名，但能决定地名的原始来源吗？

**研究对象**：景德镇、明州—庆元府—宁波府；对照上海/青龙镇。  
**日期**：2026-11-22　**阶段**：P1 中国地名史，P2外国比较及P3商标法制度史未启动。  
**证据状态**：清代《景德镇陶录》古籍在线全文、《旧唐书》卷40、《新唐书》卷41、《明史》卷44及《宋史·宁宗纪》在线文本已核；景德镇2025年吴红云、邵建春陶瓷年款论文**仅核正式摘要**，其湖田窑发掘报告和论文全文尚未逐页核对；尚未找到宋真宗景德元年“赐名景德镇”的同期诏令。

## 一、问题转向

上一轮上海显示：在宋代税务、港口与聚落中使用的“上海”，终于成为元代县名，但不能把浦、务、镇、县当作唯一必然次序。这里再加入两个控制案例：

- **景德镇**：一个产业集群的商品声誉后起非常突出，但正式名称来自帝王年号的传统记载；后世“景德年制款识先行造就镇名”被新的考古比较研究质疑。
- **明州／宁波**：唐738设州取四明山之名，宋代港口贸易繁盛远在设州后，宋1194/1195升庆元府又与皇帝潜藩/改元有关，明1381改宁波府有政权名号避讳解释。国际港口功能不是738年“明州”得名的原始词源。

因此要区分 **NAME_ORIGIN**（最初何时为何用这个名字）与 **NAME_DIFFUSION**（怎样凭产业、贸易及制度被更多人识别）和 **ADMINISTRATIVE_RENAMING**（国家怎样重新选择或改名）。

## 二、景德镇：年号命名与“景德年制”底款传说必须分离

### 2.1 现有文本链

- 景德镇市政府2024年《景德镇陶瓷文化生态保护区总体规划（2021—2035年）》历史沿革条：宋属江东路饶州，以真宗年号“景德”为名置景德镇。1991《景德镇市志》、1988《景德镇市地名志》亦均记景德元年1004年取年号；这里属于**现代地方史与旧地方志记录**。
- 故宫博物院词条载此地曾称新平、昌南，宋景德年间改名，以瓷茶贸易发展；词条公开搜索结果可见，但本轮打开页面超时，标 `OFFICIAL_SEARCH_SNIPPET_ONLY`。
- 清代蓝浦《景德镇陶录》卷1有“景德镇属浮梁之兴西乡，去城二十五里，在昌江之南，故称昌南镇……至宋景德年始置镇，奉御董造，因改名景德镇。”此为清代作者对宋代的记述，**不是1004年的原始诏令**。同书其他卷涉及进御瓷、景德款传说，须按来源和年代另外核。
- 景德镇地方信用平台刊载《“赐年号”与“底款”说》称：目前尚未找到宋真宗亲自将年号赐给该镇的直接同期文字；它列举年号命名和陶瓷底款扩散的竞争解释，并倾向底款说。**该文是地方评论性史源研究，不是已通过考古的定论**。
- 2025年吴红云、邵建春《北宋“景德年制”瓷器款识新考》（《中国陶瓷》2025年第6期）在正式知网摘要中明说：根据湖田窑发掘报告和宋代其它名窑款识研究，暂未发现可靠北宋宫廷瓷器的帝王纪年款；清代“景德年制”说是明永乐年号款习俗倒推早宋之误。**注意：论文也支持“宋真宗赐年号命名”的传统叙述，论文摘要本身并未出示诏令原档；这两个断言的证据门槛不同，不能把作者支持命名解释自动升级成命名诏令已发现。**

### 2.2 三个不同的事实状态

1. `REIGN_TITLE_NAME_ASSOCIATION`：景德镇名称同景德年号有关，地方史与晚出古籍一致——**历史文献支持，直接同期赐名令待核**。
2. `IMPERIAL_BESTOWAL_DOCUMENT`：宋真宗亲赐名且因为当年瓷器质量、要求写款——**需原始诏令或同时代史料，目前未证**。
3. `JINGDE_BOTTOM_MARK`：宋代贡瓷款“景德年制”造成地名广泛传播——**清人解释及地方评论有说法，2025专业论文摘要明确提出反证，考古支持度低，暂不得当事实**。

### 2.3 市镇经济与行政层级

景德镇初为浮梁县辖镇，最初正式命名时并非独立县或现代地级市。景德镇市政府2024规划载唐代新平县→新昌县→浮梁县、元浮梁升州、明清御器厂与县辖镇、1949年景德镇分立设市、1953年为省辖市。宋代青白瓷的声名与元明清陶瓷官营制度发展应分期，不能把**元浮梁瓷局与明御器厂的制度**倒置为宋1004年已经成立的“御窑厂”。

对“昌南镇”汉字的字面解释也不能直接推出外国词语词源；外国地名及相关语音传播问题留在P2，当前不研究。

## 三、明州：先取山名置州，后海贸成长，继而被政治性改名

### 3.1 明州设州的古籍明证

《旧唐书·地理志》卷40：开元二十六年738年“于越州鄮县置明州”，天宝元年742“改为余姚郡”，乾元元年758“复为明州，取四明山为名”。同条记鄮县及奉化、慈溪、翁山等；《新唐书·地理志》卷41更明说采访使齐澣奏以越州鄮县置明州、以境有四明山名。

这份记载说明“明州”在后出史家看来是**以当地四明山命名**，原始738年奏请正文尚未取得；唐宋行政通名变换（明州↔余姚郡）并不是临时港税机构命名。

### 3.2 港口与城市空间形成在原命名之后

宁波地方史报道：821年明州刺史韩察修州城/子城，898年黄晟筑罗城，三江口港市繁荣。广州博物馆市舶制度研究、宁波考古研究均指出992年两浙市舶司迁明州、999年明州另置市舶司。这里需分开：
- 738：名称取自四明山的州行政建置；
- 821及其后：州治与城市建设；
- 992、999：北宋对外贸易管理机构的调整/设立；
- 后期贸易繁盛说明名称在市场与外交网络中的扩散，**不是该名称最初产生的原因**。

### 3.3 庆元府：年号起始年与升府事件年存在一个易被忽略的差异

《宋史·宁宗本纪》在绍熙五年**1194年十一月**记“升明州为庆元府”，同时下令“明年为庆元元年”。清《鄞县志》也写绍熙五年十一月升府、宁宗曾领明州观察使，因以其潜藩升格命名。部分地方历史和编年书则用**1195年庆元元年**作为庆元府之始。

**结论：1194年升府有纪事明文；1195年为年号开始和行政沿革常用纪年，两者不应未经说明混成同一时点。** 但本项目尚未查到1194升府决定从哪天实际实施，府署何时换印及具体巡检文书，所以不把1194或1195唯一化为所有类别的正式生效日期。

这一发现与景德镇年号命名相似，但有更直接的本纪记载，进一步强化“建置日/改元日/正式改名实际生效日”三轴分开。

### 3.4 1381宁波：从四明山名到新王朝政治更名

《明史·地理志》卷44记“太祖吴元年十二月为明州府，洪武十四年二月改宁波”，即1381年。《明一统志》卷46亦记录明州府改宁波府。宁波地方历史与明代《大明一统名胜志》载原因与避新王朝国号“明”重名有关，后者还记有“海定则波宁”的命名故事。

**史料层级**：
- 1381年二月改宁波府——《明史》明文记录；
- 为避国号而改名——地方史/明代后出文献所作原因解释；
- “海定则波宁”的皇帝对话——明代后出叙事，不能没有同期原诏令便写为现场口语事实。

同一地方由山名明州→政治年号庆元府→明朝避国号而更名宁波府，其间港口经济可保持重要位置，但**名字和产业交易功能的变化并不同步**。

### 初步机制模型（均需继续检验）
- `ORIGIN_SOURCE`：山川地形、方位、旧城、人群、年号、官命等。
- `ECONOMIC_AMPLIFIER`：物产工艺、港口、榷酒、市场交易传播地名和提高识别度，但不总是词源。
- `INSTITUTIONAL_CONVERSION`：州郡、镇、县、府级别采名与更名是独立事件。
- `POLITICAL_RENAMING`：避国号、纪念、潜藩升府、年号使用。
- `LATER_EXPLANATION_RISK`：清人陶瓷底款、明人命名皇帝对话等后出解释不得当作同时代事实。

## 五、需要继续推进的反证工作

1. 景德镇：找到北宋景德元年至景德四年涉及浮梁县景德镇设镇的**同时代文书或原始纪年器物**；查宋代诗文、职方志/行政奏议。年号命名与直接赐名令分开。
2. 宋贡瓷“景德年制”：取得吴红云、邵建春2025《北宋“景德年制”瓷器款识新考》全文与其所引湖田窑考古报告，核“没有可靠实物”论证的具体样本和出土纪年，严守版权，只留元数据和原创评述。
3. 鄮县→明州：查738年齐澣奏置明州原诏、四明山古地图和《元和郡县图志》对应条；不能将“取山名”倒解为山名因明州建置而新造。
4. 明州市舶司：从《宋会要辑稿》《续资治通鉴长编》对992迁置、999另置分别建立财政机构证据；不要把两者视作一次建署。
5. 庆元府：对读《宋史·宁宗本纪》的1194十一月升府与《宋史·地理志》、宋《宝庆四明志》等1195口径，明确定年是改元、改名、升府还是府官上任。
6. 宁波府：核明1381年省部原始更名诏令与“避国号”“海定则波宁”两种解释的来源传承，区别真实政治命令与后世命名传说。
7. 加入完全没有成为高层行政地名的制瓷镇、商贸港作为负例，防止以景德镇/宁波的知名结果反推命名必然性。

## 补证（2026-11-22）：先有窑业，再有景德年号名的史料分层

故宫博物院“湖田窑”条目根据遗址考古指出，**五代（公元907—960年前后，属于10世纪，并非公元5世纪）**湖田已有青瓷和白瓷烧造，宋代进一步创烧青白瓷。另在故宫藏品“景德镇窑青白釉双鱼碗”的学术背景中，记载江西九江一座北宋**咸平三年（公元1000年）纪年墓**曾出土早期青白釉钵，为宋初相关陶瓷生产提供前于景德元年1004的实物线索。

**可支持**：区域陶瓷生产和相关器物类型的历史早于景德年号入镇名的通常年代。这使“景德镇名出现才有该地制瓷业”不成立，也可作为区分产业发展与地名形成的正面证据。

**不可支持**：1000年纪年墓的年份并不必然等于钵的烧制年份；其具体生产窑口尚待原考古报告、胎釉检测与学界归属意见核验。也不能用“瓷业更早”推断1004年皇帝亲赐诏令已经存在或“景德年制”北宋贡瓷款识真实存在。
