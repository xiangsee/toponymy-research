# P1-D 札记01：隋唐州郡更替、杭州与梓州——行政通名变化与地方专名延续

**阶段**：《详见》中国地名史 P1-D｜2026-11-22。**状态**：《隋书》卷29、《旧唐书》卷40、卷41等在线传世史料已核读；现代CHGIS核其历史时段。未通读《元和郡县图志》全部杭州卷，关键唐代改制原始敕令仍待查。**不进入世界地名比较和商标法。**

## 一、必须先区分“州/郡”通名与“杭州/余杭/梓州”专名

地名的形式为 `place_specific_name + generic_admin_type`，但同一行政区域在不同时代对应专名也可能变化（例如“杭州↔余杭郡”不只是去掉州、加上郡）。

**全国性制度切换**：
- 隋开皇三年583年废郡，州县结构调整；大业三年607年实行州改郡（卷29《隋书·地理志》）。
- 唐武德初以郡改州，贞观元年627年并省大量隋末、唐初临时设置的州县（《旧唐书·地理志》序）。
- 唐天宝元年742年州改郡；乾元元年758年再改郡为州（《旧唐书》州郡条、《廿二史考异》）。
- **制度称谓改变不等于历史地理对象自动不变**：同时可能分县、并州、迁治、改变上级隶属等；须逐条建立事件。

## 二、案例C050“杭州／余杭郡”：通名、专名和行政治所三条变动链

《旧唐书》卷40杭州条：“杭州，上，隋余杭郡。武德四年……置杭州……天宝元年改为余杭郡。乾元元年复为杭州。”
同卷钱塘县：“隋于余杭县置杭州，又自余杭移州理钱塘”，后有移州治柳浦、再迁等记述。

**可直接支持的三条链**：
1. 行政名称：隋杭州，炀帝余杭郡 → 唐武德四年621年杭州 → 742年余杭郡 → 758年杭州。
2. 行政中心：早期因余杭县设州，后来迁州治钱塘等；**州名没有随治所迁移而必然更改**。
3. 县级同名：余杭县与余杭郡不是同一层级；州治在钱塘时仍使用杭州/余杭郡等名称。

**必须特别避免**：将“余杭郡在742年存在”写成“余杭县于742年更名为杭州”，也不能据此断言现代杭州辖域和唐代杭州相同。

复旦CHGIS将742—757年余杭郡建独立行政记录，将758年后杭州另建州记录，且时间/空间范围需留版本。CHGIS对余杭郡在该时段辖境同杭州的断言是历史地理研究的复原，不等于郡治迁移、州县变化可全部忽略。

## 三、案例C051梓州—梓潼郡：两种名字来源并不互相矛盾

《旧唐书》卷41梓州条：隋新城郡，武德元年618年改梓州，天宝元年742年改梓潼郡，乾元元年758年复梓州。又称“梓州所治，以梓潼水为名也”。

**命名关系**：
- 梓州中的“梓”与梓潼水相关，是《旧唐书》提供的古人来源解释；
- 梓潼郡是行政名称，不可将它与梓潼县、梓潼水一概相等；
- 州名“梓州”和郡名“梓潼郡”专名不是字形完全相同的“梓+州→梓+郡”；因此制度改革有时同时改动专名部分。

唐武德、天宝、乾元反复采用不同名称，这里可以解释政权为什么不断对行政称谓作规范，但不能用名称的字面决定实际辖境全部不变。

## 四、负样本：潜州被废而于潜县回归杭州

《旧唐书》卷40杭州属县於潜条：“武德七年，置潜州，领於潜、临水二县。八年，废潜州及临水县，於潜还杭州。”

**可观察事件**：
- 624年新置潜州，以於潜、临水为辖县；
- 625年潜州撤销，临水县同时并撤，於潜县回到杭州管辖；
- 州级临时名称“潜州”退出行政体系，但县名於潜仍保留。

这提供了一个与此前侨郡撤并不同的**唐初短命州**：未必由南迁侨置造成，而是战乱平定后的临时分置和再合并。不能将所有名称撤销一律解释为侨置制度的终结。

同卷钱塘、盐官等县反复分置省并，也说明“县名被停用”和“实体的土地消失”不是一回事。

## 五、名称选择的三种张力

1. **地方记忆与旧名资源**：杭州沿用余杭、钱塘地区既有名称体系；梓州从地理水系语词选用名称。
2. **国家制度统一**：以州/郡通名切换形成普遍行政格式，但专名变化并非总是机械对应。
3. **管理规模与行政成本**：唐初权置州县较多，贞观初并省；潜州一类短期政区说明治理秩序调整可以使某些正式名称很快退出。

这是研究判断而非能直接从两例推导出的全国地名存续率。应补统计所有州县更名/撤并与实际地域指称的关系，避免幸存者偏差。

## 六、阶段性结论及反证

- **可证事实**：《旧唐书》杭州、梓州、潜州沿革及742/758年州郡名称切换。
- **现代推断**：“正式行政通名的全国性统一”和“地方专名的文化/治理连续性”可能相对独立。
- **不成立的过度推断**：唐朝州郡名称所有时候仅改一个“州/郡”字；短命州名被撤销说明居民不再使用任何类似地名；杭州的“杭”更早词源已由唐代州名解释直接证实。
- **研究问题**：隋唐对同名州、郡、县的命名消歧政策及其实施清单；为何有的州名与郡名采用不同语词；古地名是因县名上升、山川资源、政治事件还是皇帝避讳而变？
