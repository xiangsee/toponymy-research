# P1-A 札记04：目与无终——商周名称的多重功能和未证的转化方向

日期：2026-11-21。研究阶段：中国地名史。源核查状态：已取得专业研究的卜辞、金文著录号及部分古籍记载；**未独立核读全部甲骨高清原片、《殷周金文集成》原拓**。

## 1. 问题分解
甲骨字形／铭文释读 → 该字在特定句子中是不是专名 → 专名指人、族、地方还是政权 → 指向何种历史地理对象 → 两种名称之间是否真有承继关系。任何一步未证，后续不自动成立。

## 2. “目”：普通词与专名角色并存
- 普通名词（眼睛）：港中大《汉语多功能字库》引《合集》165正；钱唯真《论甲骨文字形与字词义之关系》另举《集》456正。
- 动词（观察/侦察）：港中大字库举《合集》6195；钱唯真另举《集》6194。编号差异待查原片，不能把动词“目”错误记录为地点。
- 人名：赵鹏《读契札记一则》引用《合集》14034等，以“子目”“目”作为人物称谓。
- 田猎地点：赵鹏列《合集》29285、29286、33367，包含“王其田目”及“至于目北”等语境。
- 族氏名：王伟2019称“目”为族地同名的例子；港中大字库举“目爵”及“屰目父癸爵”；汉典提供《殷周金文集成》7494为“目爵”的著录线索。

**可支持的最小命题**：一个字形可在不同文本里分别用于眼睛、观察动作、人名、田猎地、族氏。**不可证明**：目族一定先有、目地后有，也未定位该田猎地在现代地图的精确地望。字的象形本义不等于专名的真实词源。

## 3. “无终”：考古器物、历史政治称谓、行政县名相互间隔
- 石蝶《商代中期有铭青铜器探讨》（《故宫博物院院刊》2006年第4期，第41—42页）记无终戈：《殷周金文集成》10881、1965年陕西绥德墕头村墓葬出土、陕西历史博物馆收藏、通长32厘米、铭文作“无终”（传统隶读亦作“亡终”），该论文定为商代中期。又引《甲骨文合集》4307反作为商代相关族氏活动线索。
- 《左传·襄公四年》有无终子嘉父使人如晋请求和诸戎的政治活动记录。
- 《汉书·地理志》在右北平郡无终县下有“故无终子国”，是行政地理追述。
- 《后汉书·吴汉传》唐李贤注则将“无终”解释为山名→国号→汉县名。
- 裘锡圭的相关族徽研究（经王伟2019引用）提出族氏称号逐渐形成部落/联盟名称的路线。
- 顾炎武《日知录》疑惑无终活动地区在晋太原与右北平相距甚远，讨论迁徙可能；韩嘉谷《试探无终》（《北京文博》2006年第1期）对无终山地望与迁徙提出另一套分析。

**可支持**：名称在商代铜器、春秋政治叙事和汉代县名中分别得到记载。**不可支持**：陕北器物的出土地即族群最初起源地；商代、春秋、汉代各所指都已证为一个没有中断的实体；唐注山名先于族名已有同时代证明。

## 4. 重要分歧与来源批判
A. “族氏→群体称号→地方”：依赖族徽释读及跨时代连续证据，当前方向未证。
B. “山名→国号→县名”：唐李贤注属后代解释，不能替代商代命名现场。
C. “同名与迁徙”：顾炎武、韩嘉谷等提出不同移动方向，需要独立的时间、文献、考古与地望证据。
D. “未必完整连续”：同名异地、后世附会与材料缺口均需作为反证保留。

## 5. 对分类框架的修正
**字形相同 ≠ 词义相同 ≠ 专名类别相同 ≠ 历史地望相同 ≠ 族群连续 ≠ 名称转化方向已证。**

原“族地同名意味着族名必然早于地名”的单向假说暂时降级。对于这两个样本，可记录多种名称功能，但不得补出未能证明的起源因果链。
