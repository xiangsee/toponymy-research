# P1-A / 札记03：早期地名的出土文字压力测试
**阶段**：中国地名史 · 商周甲骨金文；**版本**：v0.1，2026-11-21
**目标**：从“学者对地名的来源分类”前进一步，验证具体器物/甲骨上的名词究竟承担何种功能。**不作国外比较，不提前进入商标法。**

## 1. 研究对象与最重要发现

本轮选择两个器物实证案例、一项甲骨释读反证、一组现代学术归纳：

| 研究对象 | 出土／编号 | 可观察到的命名关系 | 当前能确认 | 尚不能确定 |
|---|---|---|---|---|
| **何尊** | 1963年陕西宝鸡贾村；《殷周金文集成》6014（通过现代古文字研究文献定位） | 「成周」「大邑商」「宅兹中国」：都城、政治中心、相对地域观念在同一段铭文并存 | 器物、字数、相关文字及训诰背景有国博、宝鸡收藏资料 | 「中国」具体指涉、成周营建细节及铭文局部释读仍有争论；不可等同现代主权国家名 |
| **宜侯夨簋** | 1954年江苏丹徒烟墩山；《殷周金文集成》4320（由古文字文献对照定位；部分转载把「1.4320」连写为「14320」，待校） | 「迁侯于宜」：已有地名与迁封、爵号、土地人口配置相联系 | 国家博物馆馆藏说明、镇江博物馆史料记录及出土文献研究一致支持“迁侯于宜”的核心情节 | 「宜」的实际地望及虞／吴／宜关系有争议；铭文总字数与现存可辨字数不同 |
| **卜辞中的「方」** | 《殷虚文字乙编》107（现代论文指向的甲骨著录编号；原片需调取） | 「方」可能是方国简称或泛称，不一定是某独立方国的专名 | 2025年李林论文的**国图公布摘要**明确指出对「方方」旧连读的修正 | 尚未阅读该论文全文或核对甲骨高清照片，不可独立宣告旧说已最终推翻 |
| **族地同名** | 王伟2019年论文梳理「目」「无终」等 | 族名/居地名/国邑名/姓氏可能共用词形 | 现代学术著作提出大量案例和转化路径 | 不能仅凭同名得出“族名先，地名后”；原始器物编号、字形、地望需另证 |

### 1.1 文献“最早见”不等于历史上最早出现
何尊中出现「宅兹中国」，可以说是**目前所知的早期文字记录**，不是“中国”一词或空间观念在该刻铸时才由何尊创造。国家博物馆对“中或（国）”的理解，强调其早期区域/政治中心意味与后世国名不同；2021年赵永春、迟安然论文摘要则提出早期「中国」兼具地理中心、京师、政治政权等多重义。后者是**学术解释差异**，不是与器物事实矛盾。

### 1.2 受封地≠出土地≠诸侯最初的封地
宜侯夨簋出土地可定位于今江苏丹徒，但姚草鲜2023年论文主张铭文“宜”在河南宜阳；2018年王一凡研究系统整理1954年以来的多种释读及地望争论。**必须分别记录三个空间事实**：
1. 器物发现地点 `findspot`；
2. 铭文提及的古地名 `named_place`；
3. 学者假定的地望 `proposed_location`（可以是多种竞争方案）。

### 1.3 「方」可能并非专有名词
国家图书馆刊布《文献》2025年第1期目录和论文摘要：李林《殷卜辞所谓“方方”献疑》以《殷虚文字乙编》107为对象，基于清晰照片质疑旧“方方”连读，并提出“方”作为方国简称/泛称的解释。
**这只能归入 `ABSTRACT_READ / PRIMARY_PENDING`**；原照片、具体行次、古文字释读尚未独立检验。研究中不能把每次“方”的出现都自动识别为国名。

## 2. 本轮形成的四条证据方法

### A. 名称对象要分开
- `name_form`：一个词形/写法，如「宜」「中国」。
- `referent_type`：地点、地域观念、聚落、王畿、政治共同体、族群、爵号、人名、氏姓或尚无法判定。
- `attested_context`：这个词在具体甲骨/铭文句子中的语法与政治功能。
- `token_vs_type`：一次记录不必等于唯一稳定的专名词条。

### B. 器物物理事实与文本释读分开
- `artifact_id`、藏地、出土地、年代范围、考古报告；
- `catalog_id`（如《集成》6014、4320）、字数采用“计铸字数／可见字数／可释字数”不同字段；
- `transcription_variant`：不同学者的释文及不确定字；
- `interpretation_claim`：从释文推导的历史结论。

宜侯夨簋：国博与镇江博物馆记总铭文**126字**，镇江馆又记**现存118字**；王一凡论文称**115字可辨认释读**。这涉及不同统计口径、器物残损及释读标准，不能简单视为彼此相互否定。

### C. 名称关系不能默认方向
- 「宜」成为「宜侯」的一部分：铭文支持地理地点与政治封号关联；
- 「目」作为族氏/地名：现代研究归纳使用，先后方向未直接核实；
- 「中国」由空间/政治概念向后世国名发展：是跨时代语义史，应另建连续文献链。

### D. 必须有反例层
存在“被认定为专名，实际上可能是省称或泛称”的情况，就不能使用“甲骨文中检索出词形 X ⇒ X 是独立方国”的自动程序。先确认字形、断句、上下文，再查对象与地望。

## 3. 由此形成的工作假说（非已经证实的历史定律）

**H-SZ-01｜专名功能跨域**：同一词形可能在特定时代作为居地、政治共同体、族群和人物称号被重复利用，先后并非总能辨明。

**H-SZ-02｜政治行为强化名称的可识别性**：迁封、建邑和行政赋名可能强化某称谓与地域或政治身份的联系，但不一定创造原始地名。

**H-SZ-03｜空间观念→地域指称→政治意义不是单一路径**：何尊可作为带有空间与政治语义的早期材料，但不能单靠一器补足整个“中国”概念史。

**H-SZ-04｜释读错误可引发地名实体误建**：李林关于“方方”的2025年论文摘要提供一个明确待测反例，需读原文和原甲骨高清片后才可升级论证。

## 4. 研究局限

1. 两件青铜器有明确馆藏与现代公布的铭文信息，但没有在此库重新发布拓片、古文字描摹或未经授权扫描件。
2. 《集成》编号经学术来源核对，仍需按纸本《殷周金文集成》与出土报告复校。
3. 卜辞「方」目前只有原甲骨编号线索 + 2025年论文摘要，**不是独立释读完成**。
4. 族地同名来自王伟2019年的研究归纳，**不是本轮自行完成的全部甲骨/金文对读**。
