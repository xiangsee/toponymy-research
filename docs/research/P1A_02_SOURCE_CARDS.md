# P1-A / 基础文献来源卡（第一批）

**标记说明**：
- **TEXT_LOCATED**＝找到并核读在线古籍文本位置，不代表已做版本校勘。
- **SECONDARY_READ**＝直接阅读现代学术研究的在线文本，但尚未逐件复核其引用的古文字拓本。
- **BIBLIOGRAPHY_LOCATED**＝已核实书目信息，相关正文尚未完整核读。
- **NEXT_PRIMARY**＝仅建立原始材料线索，待取具体版本与卷页。

## S-CARD-01：商周甲骨/金文与王伟论文（考古文字研究）
- **类型**：现代研究论文；主要处理出土文字专名。
- **书目**：王伟，《商周地名的来源与衍化及其史学价值——以甲骨、金文资料为中心》，《史学史研究》2019年第4期。
- **链接**：https://cssn.cn/lsx/lsx_zgs/202210/t20221024_5552572.shtml
- **本轮核读**：研究归纳族地、人地同名、同地异名、异地同名，以及地名衍化为国邑名、姓氏、人名。
- **不能证明**：每个上古名称的确定词源、精确地望或名称先后。
- **状态**：SECONDARY_READ。**下一步**：选出文中2—3件有拓本释文的例子，追溯出土文字编号与释读争议。

## S-CARD-02：《汉书·地理志》（传世早期行政地理资料）
- **类型**：东汉史学著作对西汉行政地理的记载，现代在线页面为附颜师古注版本。
- **书目**：班固《汉书》卷二十八《地理志》，应注意正文与后世注文分界。
- **链接**：https://zh.wikisource.org/zh-hans/漢書顏師古註/地理志/地理
- **核读位置**：京兆尹下的「华阴」；汝南郡下的「上蔡」及「新蔡」。
- **不能证明**：所有被提及的古国、古县原始建置时间或词源无异说。
- **状态**：TEXT_LOCATED。**下一步**：与中华书局点校本页码及相关出土地理材料对勘。

## S-CARD-03：应劭《汉官仪》（经后书所存引文）
- **类型**：东汉已佚/非完整原书文本，经北魏、宋代引录可追索。
- **传承**：《水经注》卷二引《汉官》；《太平御览》卷157作应劭《汉官仪》相关引文。
- **链接**：https://www.shidianguji.com/book/CADAL02030776/chapter/1l1xa098euk8w ；https://www.shidianguji.com/book/NGJ8924120000010602678/chapter/1lwxjmtl1vr4r
- **本轮核读**：郡名六种来源，明确对象为郡名，不是全国全部地名。
- **不能证明**：秦帝国曾以此作为统一规则，或每个例证都属秦代。
- **状态**：TEXT_LOCATED（间接传本）。**下一步**：完整比对不同版本和校注。

## S-CARD-04：《水经注》卷二（地理记述及前代引录）
- **类型**：北魏郦道元著，兼水道、地名、地望、古籍引文。
- **链接**：https://www.shidianguji.com/book/CADAL02030776/chapter/1l1xa098euk8w
- **本轮核读**：河水章节引《汉官》有关郡名来源；另引应劭《地理风俗记》解释敦煌、酒泉及张掖。
- **不能证明**：被引古人所说必是最初发生的客观事实。
- **状态**：TEXT_LOCATED。**下一步**：按「郦道元自述／引用他书／后世校勘」分别标注。

## S-CARD-05：《元和郡县图志》（唐代行政地理总志）
- **类型**：唐李吉甫编撰，以政区、沿革、方位、交通及地方地理为重点。
- **可读传本**：https://zh.wikisource.org/zh-hans/元和郡縣志_(四庫全書本)/全覽1
- **本轮核读**：卷中有华阴从阴晋、宁秦到华阴及唐代后续改名的记录。四库整理本说明唐书原有地图已亡，而且卷帙有缺。
- **不能证明**：现存四库本完整保留唐初图、卷次与全部文字，或其地望必无误。
- **状态**：TEXT_LOCATED（晚期整理传本）。**下一步**：与中华书局点校本或早期版本核对卷页与异文。

## S-CARD-06：华林甫《论两汉时期中国地名学的奠基》（现代学术）
- **类型**：地名学史研究，对《汉书·地理志》及后汉解释的历史贡献做文献分析。
- **书目**：华林甫，《中国史研究》1996年第2期，第14—25页。
- **在线全文入口**：https://iqh.ruc.edu.cn/old/zglsdlyj/lsdl_dmxyd/dmxsyj/10f4cf14e863413ba4cab26f8b6018e8.htm
- **可支持**：地名解释学在两汉的重要发展、地名学史研究线索。
- **不能证明**：替代古籍文本与具体地名的实证考订。
- **状态**：BIBLIOGRAPHY_LOCATED（公开页面显示出版信息与内容摘录）。**下一步**：按页核实作者原刊论证与引文。

## S-CARD-07：复旦大学 CHGIS 时间序列
- **类型**：经过历史地理考证的数据产品，辅助古今政区位置和变化。
- **机构**：复旦大学中国历史地理研究所。
- **链接**：https://yugong.fudan.edu.cn/info/1361/15131.htm
- **已定位**：项目介绍其时间序列从秦统一至清末，政区点/面均有文字说明。
- **不能证明**：特定地名的词义起源或上古时期地望。
- **状态**：BIBLIOGRAPHY_LOCATED（数据尚未下载和逐条审核）。

## S-CARD-08：华林甫《中国地名学史研究》（学术专著）
- **类型**：中国地名学史框架性著作。
- **书目**：华林甫，山东画报出版社，2021年3月。
- **机构出版消息**：https://iqh.ruc.edu.cn/kxyj/bscg/bab46789c1a54cc2ac69512d63f84328.htm
- **已定位**：出版消息明确本书上篇以时序梳理传统地名学史。
- **不能证明**：出版消息替代书中各章论述与原始参考文献。
- **状态**：BIBLIOGRAPHY_LOCATED。**下一步**：书目及章节页码、论文版本逐章核验。

## 文献如何进入案例记录

每条个案断言必须列明源头层次（出土文字／传世古籍／原书引文／古人释源／现代研究／当代地理数据），并单列一个 **not_established** 字段，写明现阶段还无法由该来源证明什么。
