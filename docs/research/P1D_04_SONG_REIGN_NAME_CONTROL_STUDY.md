# P1-D 札记04｜宋代年号地名的压力测试：淳化县、嘉定县、宝庆府和“非年号”的嘉定府

**日期**：2026-11-22｜**研究边界**：P1 中国地名历史，未进入国外比较P2和商标法史P3。  
**材料状态**：《宋史·地理志》卷88/89数字古籍文本、《明代大明一统名胜志》宝庆府、《清代淳化县志》及《直隶邠州志》古籍电子文本、复旦CHGIS嘉定县（含史源异文）、上海市民政局2023复旦历史地理研究、上海2026政府嘉定概况、嘉定县首任知县地方史已核；陕西《淳化县志》PDF经网页文本读取，web PDF截图请求超时，故只标 **PDF_TEXT_ONLY_SCREENSHOT_FAILED**，不声称已核视觉原版；嘉定《奏建嘉定县省札》为现代文章节录，尚未见可复核的宋代奏札手稿/完整宋元刻本。

## 1. 研究的核心突破：同样“用年号作名”，至少有三种不同行政操作

| 案例 | 早期设立及时间 | 行政动作 | 为什么采用名字 | 资料与限制 |
|---|---|---|---|---|
| **淳化县**（陕西） | 宋太宗淳化四年 **993** | 从耀州云阳县的梨园镇及六乡析置新县 | 后代县志及《陕西通志》明确认为“以年号名县” | 旧志引《长安志》提出边远林壑盗贼与管理困难作为设县理由；**设县动机≠取名动机** |
| **嘉定县**（江苏昆山析置、今上海嘉定） | 地方志/政府采用嘉定十年十二月初九（中国旧历1217年，折合**1218-01-07**）；**《宋史》另记嘉定十五年（1222）** | 平江府从昆山东境析五乡设新县；后选择“嘉定”宁宗年号 | 《宋史》明言“以年为名”，现代转载旧《省札》说“请以年纪名” | 时间冲突未解决；**现代二手文献27都、28都数字也不一**，完整《省札》原本需核 |
| **宝庆府**（湖南） | 宋理宗宝庆元年 **1225** | 邵州因理宗潜藩升为宝庆府 | 《宋史》明确“以理宗潜藩升府”；明曹学佺《大明一统名胜志》明确补充“从宝庆元年号也” | **升府的政治身份理由**与**选用的年号文字**是两条不同证据；宋代原始改名诏令待核 |
| **嘉定府**（四川乐山，非嘉定县） | 宋宁宗庆元二年 **1196** | 嘉州因宁宗潜邸升为嘉定府 | 当时宁宗使用的是庆元年号；**嘉定年号1208年才开始**，故不可能由后来的“嘉定年号”引发1196取名 | 《宋史》明确潜邸升府；**嘉定府二字最初为何选用**尚待更早文献，不能臆测“嘉州＋安定”一定是原始来源 |

### 决定性的负例：嘉定县与嘉定府
《宋史》卷88嘉定县条：“嘉定十五年，析昆山县置，以年为名。”
《宋史》卷89嘉定府条：“本嘉州……庆元二年，以宁宗潜邸，升府。”

**同字形 / 同层级?** 县名 vs 府名。
**同一地方?** 上海嘉定 vs 四川乐山，不同地域。
**同一起源?** 上海嘉定县被解释为以宁宗嘉定年号为名；四川嘉定府**1196年早于宁宗嘉定年号1208年**，无法使用“1208年以后嘉定年号赋名”解释1196嘉定府。嘉定府名称的其它来源仍须查。

这个例子证明：`name_form == reign_title` **不是足以证明年号起源的条件**；必须至少加入 `naming_event_date >= reign_start`、`referent_id`、`specific_source_quote`，并注意**年号刚好同名不等于有使用年号命名的政策记录**。

## 2. 淳化县：县制建立的理由不是年号本身

清洪亮吉《淳化县志》卷一、孙星衍《直隶邠州志》卷一保存较早《长安志》材料：
- “云阳县梨园镇，在金龟乡……淳化四年建为淳化县”，从原云阳县分金龟、平泉、古鼎与山后甘延、温丰、威远六乡；
- 书中又引太子中舍人黄观之言，因“此地山林深僻，多聚贼盗”而建县。
- 后代史志指出“以年号名县”。

**这里至少有两种问题**：
- **为什么需要设县？** 据被引旧材料，是偏远地点治理及案件/盗贼、行政管理困难的官方理由；这是宋官府的立场，不能改写为当时人民的道德属性。
- **为什么叫“淳化”？** 历代地志一致以宋太宗淳化年号解释；却不是因为那一地方本身必须叫“淳化”，也不等于宋人首次出现这两个普通字。

### 特别的文字校勘
《宋史·地理志》部分传本写“黎国镇”；清洪亮吉校称应是“梨园/黎园镇”，认为“国”为“园”之传抄或刻印之误。因此即使正史里的古地名汉字相同/不同，也须辨“原字/异写/误写”，不能把“黎国镇”自动建成一个与“梨园镇”并存的第二个行政实物。

- 旧志引文： https://www.shidianguji.com/book/HY0397/chapter/1k5psgadsnfw2
- 嘉庆重修一统志卷248—250：https://wk.100ke.info/zh-hans/嘉慶重修一統志_(四部叢刊本)/卷二百四十八至二百五十
- 现代地方志PDF（仅文本已读、截图超时）：https://dfz.shaanxi.gov.cn/zslm/fzzlk/xbsxsxz/xbsxz/xys_16200/201405/P020240923605791266117.pdf

**公元纪年校验**：淳化四年=993年。现代整理的《咸阳经典旧志稽注》有“淳化四年（994）”括注，与淳化县志及咸阳市志的993记载不符，应该把这视为**现代西历折算/排印疑点**，不能把994当成另一个同级古籍年号。本项目需找到该整理本原页和宋纪年表进行最后交叉校验。

## 3. 嘉定县：宋史写1222，现代地方政府写1217/1218——不能直接选定

### 时间链的对照

- **《宋史·地理志四》**，卷88平江府辖县条“嘉定。上。嘉定十五年，析昆山县置，以年为名”：照文直算为**1222年**。
- **复旦CHGIS嘉定县**（hvd_40391）采用**1222—1294**作为县级行政节点，却在**同一条来源注释**中引用明洪武《苏州府志》卷一“**嘉定十年，割昆山置嘉定县**”，清楚保存两条相反记载。
- **上海市人民政府2026嘉定概况**和**央广2023嘉定建县回顾**采用嘉定十年十二月初九，即**1218-01-07**（旧历1217年12月9日）；
- **嘉定首任知县高衍孙**据上海纪委系统2021地方史，嘉定十一年五月（1218年6月）到任，亦为县已于1218年行政运作提供间接时间旁证。
- **傅林祥2023受上海民政委托研究**使用“嘉定十年”奏建的地方文献，并指出其先前1214官员踏勘与1217年赵彦橚、王棐奏建。
- **2023央广转述《奏建嘉定县省札》**记“请以年纪名”，并引当地东乡距县过远、司法追捕及税役管理不便作为建县申请理由。

这组材料使“嘉定十年”的证据链相对较丰富，但并不等于我们已找到原奏札宋代全文或完整批复。因此**更保守的本项目结论是“1217旧历末／1218公历初与1222构成必须明列的史料差异”**。不要直接宣布《宋史》必错，也不能用CHGIS一个时间节点删掉官方当地记载。

### 另有五乡“二十七都/二十八都”的数量差异
- 上海市政府2026页面只写“五乡”，不列“都”数；
- 央广2023历史回顾与上海纪委2021文章均写“五乡二十七都”；
- 上海民政2023傅林祥研究却写“五乡二十八都”。

这可能涉及初议/批复/分割后实际都数统计口径，或传本误差；**本轮没有原版奏札核对，必须标 UNCERTAIN**。不能未经说明擅自把28改成27或反过来。

### 为什么设县？为什么用年号？
《奏建嘉定县省札》被引原因包括原昆山极东地区距县治遥远、司法难达、税役执行成本高。这里的官府治理需求与名称选择是分开的。官方与现代文献还会把“嘉定”写成“清嘉之土、安定之地”愿景，但这属于**政治寓意解释**，未必能代表宋宁宗本人的可证原始动机。

## 4. 宝庆府：潜藩升府与年号两个不同政策层次

《宋史·地理志四》卷88宝庆府条：“本邵州，邵阳郡……宝庆元年，以理宗潜藩，升府。”（1225年）。

这条史料直接说明：**邵州的行政级别升为府与皇帝原有政治身份有关**；不能简化为因当地经济增长设府。

明曹学佺《大明一统名胜志》宝庆府条进一步说“宋理宗潜邸于此，升为府，命名宝庆，从宝庆元年号也”。这一晚出书说明**正式名称的文字选自当时年号**，但命名诏令原件尚未找到。

不同于“淳化”“嘉定”析县，宝庆是**原有州的升格改名**。复旦CHGIS记录宝庆府1225—1276、辖邵阳和新化两县，并据宋元史追踪元代升改宝庆路。它的地理边界是历史GIS分期建模，不是古代当场绘制的完整版图。

## 5. 四川嘉定府是击穿“同形年号=同一年号词源”的关键对照

《宋史·地理志五》卷89嘉定府条：
“嘉定府，上，本嘉州，犍为郡，军事……庆元二年，以宁宗潜邸，升府。”

**庆元二年1196年**，彼时宁宗年号为庆元（1195—1200），而宁宗“嘉定”年号始于**1208年**。所以嘉定府的名称**不可能由尚未开始使用的嘉定年号来命名**。其具体名称构词、已有“嘉州”与“嘉定”之间怎样发生语义转化尚待核；不能凭“嘉州+安定”构造未见的原词源。

嘉定府与今日上海嘉定**同字异地、不同级别、形成早晚不同**。这是研究地名实体去重、词源溯源及“年号同形”判断的高价值负样本。2023《宋史研究论丛》一篇论文脚注在识别南宋《嘉定甲乙志》的具体地区时，也利用“庆元二年四川嘉定府存在于嘉定年号以前”的时间逻辑做文献归属判断；但此文只是在脚注中触及该问题，不是专门考证“嘉定府两字”的最初构词理由。

## 6. 机制分类（建议加入 P1-D 研究体系）

本轮新增字段：
- `name_source_type`: `REIGN_ERA` / `DYNASTIC_OR_PERSONAL_COMMEMORATION` / `SAME_FORM_NON_ERA` / `UNKNOWN`
- `administrative_action`: `COUNTY_CARVED_FROM_EXISTING` / `TOWN_UPGRADED_TO_COUNTY` / `FORMER_PRINCE_BASE_PROMOTED_TO_PREFECTURE` / `OLD_PREFECTURE_RENAMED`
- `reign_begins`, `first_attested_name`, `institutional_event`, `record_written_date` separately.
- `governance_reason`: 例如距县远、户籍税役与司法难及；
- `selected_name_reason`: 年号、旧名承继、避讳、政治象征；
- `later_etymology`: 后人解释，不自动证明当年朝廷具体心理。
- `temporal_consistency_gate`: 如果“名称早于同名年号开始”，则 `REIGN_ERA_DERIVATION_OF_THIS_ERA` 为 **REJECTED_BY_CHRONOLOGY**；即使“名称晚于同名年号”，还需要原文证据，不能仅据时间相容就确认因果。

## 7. 下一轮建议的原始资料验收

1. **嘉定县1222 vs 1217/1218**：取得宋代《奏建嘉定县省札》最早完整文献版本，以及明洪武《苏州府志》卷一原刻、县署首任高衍孙《创县记》；考证哪一条记载可能为历史时点或版本误差。同期确认“五乡27/28都”差异。
2. **淳化县**：查《长安志》《宋史》卷地理条的正式校勘本与黄观所言的历史治理语境，核“黎国”“梨园”字形，以及某现代整理本淳化四年误注(994)的问题。
3. **宝庆府**：取得宋理宗登基后的改元、邵州升府诏书、官署更名日期和《舆地纪胜》当代近时证据，区别1225年建置/年号同年的不同事件。
4. **四川嘉定府**：追1196年从嘉州升嘉定府的原始批复，考证“嘉定”二字真正源于嘉州旧名、祥瑞词组还是其他材料，不能凭同形臆测。
5. 将这四案与景德镇、庆元府作控制比较；同样是年号字面，为什么有的行政县名来自年号，有的府名却更早？不预设宋代形成了统一年号命名政策。
6. 本阶段不引入任何地名商标法规范结论，P2世界比较、P3制度史继续按顺序等待。
