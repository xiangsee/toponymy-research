# P1-C 札记01｜地名搬家：侨州郡县与土断，名称和空间的制度性分离

日期：2026-11-22。研究阶段：中国地名史 P1-C。研究状态：已核《隋书·食货志》《宋书·州郡志》在线传世文本和现代专业研究；**胡阿祥2008专著未通读、南兰陵古地望未独立实地核查**。P2世界比较、P3商标法史未启动。

## 一、关键事实：不是简单的“移民以故乡命名”
《隋书·食货志》（卷24）将晋中原丧乱后江左侨人、旧壤之名及侨立郡县联系起来。侨置意味着原籍名在异地获得行政、人口和身份联系，而不只是民间思乡别称。该书为唐代史官编纂的历史记载，不是东晋时期直接的行政批复。

胡阿祥《东晋南朝侨州郡县与侨流人口研究》由全国哲学社会科学工作办公室2011年介绍：严格意义的侨州郡县具备原政区陷没及取旧名、侨流人口、侨置管理机构三个要素；书中逐类讨论原郡、侨郡、迁入地旧郡之关系，以及土断、分布与旧名去留。本轮只核成果介绍与公开目录，专著内容须后续读原书按页考订。

## 二、土断的两套不同解释：必须并列
- 胡阿祥《论土断》（南京大学学报2001年第2期，83—92页）官方摘要：东晋南朝见诸史载十次土断，主要整理侨州郡县、将白籍改黄籍，尽管成效有局限却持续发生。
- 陈乾康《论东晋南朝的侨州郡县》（四川师范大学学报社科版1995年第2期）论文摘要：侨置有更早制度先例，淮南、江南、汉水、益州为重要区域；土断的重点是侨人的寄寓户籍状态而不是一概废罢侨州郡县；侨政区称谓最后的废罢还受北朝和隋统一影响。
- 两者并非简单互斥，但对土断作用的因果和阶段有不同侧重。**不得把“土断=所有侨郡县立即取消”写为历史事实。**

## 三、实证样本：兰陵、南兰陵及南朝萧氏
《宋书·州郡志一》直接记有南兰陵太守及兰陵、承两个属县，并另有“兰陵郡别见”以区分侨置与原名系统。该书记行政户口及机构，为研究南朝侨郡行政身份提供较强传世文献支持。

《南齐书·高帝本纪上》有“萧整过江居晋陵武进县之东城里”的历史家族记载。今江苏常州/镇江边界附近的“南兰陵”与山东兰陵原籍之间的确切接合、东城里位置，目前地方史学界存在讨论；**移民居处不能无论证地当作某侨郡郡治坐标**。

复旦CHGIS有502—557年兰陵郡条（hvd_32370）指出梁天监元年（502）改南东海侨郡为兰陵郡，同时南徐州侨郡县土断；并记录陈永定二年（558）改为东海郡。CHGIS同页详细注明据《梁书·武帝纪》《陈书·高帝纪》等对县属和疆界推断；其界线是**现代历史GIS重建**，不是古时官方地图直接存留。

尤其重要：**南兰陵、兰陵县、502年梁兰陵郡、陈代东海郡**并不是一个地理实体始终保持同级同界。应分别记录其时间、级别、实土化和是否转名。

## 四、可观察的地名迁移与转化类型
1. ORIGIN_NAME_REUSED_ABROAD_IN_REALM：原州郡县旧名在新移居地重新采用；
2. QIAO_ADMIN_WO_SHITU：侨置行政机构与当地原有实土政区可能并存；
3. PREFIX_DISAMBIGUATION：出现“南”之类方向前缀区分同名；不能当成所有侨郡必有前缀；
4. MIGRANT_ORIGIN_IDENTITY：祖籍/侨籍身份与现居住地可能不一致；
5. TU_DUAN_REGULARIZATION：土断后户籍/行政管理关系可能调整；
6. QIAO_TO_TERRITORIAL_ADMIN：部分侨政区在当地取得实土、从侨寄变成有辖地的行政单位；
7. ABOLITION_WITH_NAME_SURVIVAL：某侨政区废止，但名称仍可经别称、县名、家族里籍延续；
8. POST_UNIFICATION_RATIONALIZATION：北朝和隋的统一与政区整理，也可能继续消除侨置、重名现象。

上述为项目分类建议，非古代法律直接规定的八个规范门类。

## 五、历史学压力测试
- 北方“兰陵”是否仍存？如果同时存续，南方名称是分支，不是原地名整个“搬空”。
- 南兰陵侨郡是否拥有明确土地？某时段从无实土变成实土，需要原文及县属证据，不能仅凭名称加“南”决定。
- 晋代侨民白籍是否与侨州郡县地址一一对应？散居于不同实土县时未必如此。
- 土断是否每次影响全南朝辖地？胡阿祥摘要还提地方范围土断；不能给单一全国日期。
- 齐梁皇室的“南兰陵人”是否等于郡治就在家族东城里？需要独立地望，不得混同人物里籍、家族居住地与郡行政驻地。
- 旧地名是否永久消失？同名后来的地方志、族谱、自然/行政用途需独立记录。

## 六、研究判断与未决事项
**支持**：早期中国存在地名随着人口迁徙在另一行政地域被制度性复用的机制，且侨置和土断与户籍、治理紧密相关。
**待证**：南兰陵具体侨置最早时点、每次改置实土化所涉地域及相关史料版本；陈乾康与胡阿祥对土断作用的研究分歧；侨州郡县的全国数量和终止比例。
**不可推断**：凡出现相同州县名即侨置；土断一定彻底取消侨置政区；南兰陵族谱记忆必与行政疆界一一对应。
