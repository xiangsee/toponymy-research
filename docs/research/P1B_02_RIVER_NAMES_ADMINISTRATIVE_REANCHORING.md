# P1-B 札记02｜山川如何成为政区：三川、河南、汉中与《秩律》地名反证

> 《详见》中国地名史长期研究；2026-11-21。只研究中国历史及地名学，不进入世界地名比较或商标法。版本 v0.1（研究札记，不是已完成的学术定论）。

## 0. 本轮最重要的修正

同一个名称至少可能涉及四种不同的事实：
1. **名称形式**：如“河南”“汉中”“梁”字面文字；
2. **名称功能**：自然地理关系、区域通称、郡县正式名称、王号／国号；
3. **所指历史对象**：洛阳周围的河南郡、其他黄河以南地区、战国魏都大梁、别的梁县；
4. **时间与证据**：某书提到名称的年代、所述地名实际对应时代、书籍写作年代、后代学者释源年代。

四项必须分开，不允许数据库按字符串自动合并，也不允许仅凭当代地图把历史名称定位。

## 1. 黄河体系：三川郡→河南郡是可记录的改名，却非“河南”概念起源

### 1.1 《汉书·地理志》的行政沿革记录
《汉书·地理志》河南郡条：“河南郡，故秦三川郡，高帝更名。”同卷又记“河东郡，秦置”“河内郡，高帝元年为殷国，二年更名”。

这说明同一河流相关的区域可以有三种行政名称形成方式：
- “三川→河南”：同一行政继承链的**更名记载**；
- “河东”：相对黄河的地理方位成为郡名；
- “河内”：政治封国与郡名的替换，名称仍带地理关系。
**不能仅从这三项推出秦汉三郡的疆界始终按黄河天然河道清晰且不变**。

《汉书》源：https://www.shiwens.cn/bookv_19604.html

### 1.2 “三川”之义的解释层级
“三川”指黄河、洛水、伊水，是古人韦昭的解释，后世《汉书地理志补注》等引其说“有河、洛、伊，故曰三川”。这是**古代解释史**，尚不是秦朝设郡现场的原始命名文书。不能把“名称有三个水系含义”直接等同于当时的全部精确行政边界。
整理线索：https://ctext.org/wiki.pl?chapter=5098299&if=gb&remap=gb

### 1.3 “河南”同时是一种可迁移的区域方位称谓
谭其骧等《我国省区名称的来源》概括了“河南”在历史时期的多种地域指向：战国韩、魏、宋等国的黄河以南区域；秦汉的河套等地区某些地理称谓；南北朝吐谷浑所在的青海黄河以南地区；洛阳周边的河南县和河南郡；唐河南道、元河南江北行省和明清河南省等。

这并不表明所有“河南”相互直接承继；名称可能出于黄河相对位置**独立再造**，也可能经过传统政区名借用。须按 referent_id + time_scope 逐条判断。
研究转载：https://www.aisixiang.com/data/115498.html
**来源警告**：这篇文章是后期转载的旧作，其提及的省级政区数量不代表2026年的现状。此处仅使用其历史名称来源分析，并准备找原始刊本。

## 2. “汉”：水名→郡名→王号／国号的可证与不可证

### 2.1 有明确记录的名称转化
《华阳国志·汉中志》写“秦惠文王置郡，因水名也”；《汉书·地理志》“汉中郡，秦置”；《史记·高祖本纪》载项羽立刘邦为汉王，王巴、蜀、汉中，都南郑。可分层证明：
- “汉”是水名；常璩在晋代明确解释汉中郡取水名；
- 秦汉时代“汉中”是郡名；
- 西汉前206年刘邦封号汉王与其王地有关；后来的“汉朝”国号与此封号存在政治连续关系。
再后来“汉人”“汉族”的社会认同形成是复杂过程，不得写成“汉水直接产生汉民族”。

### 2.2 保留的三类争议
**纪年异文**：《华阳国志》原传本有“周赧王二年”，部分校注据《史记·秦本纪》等校“三年”，不能未经说明就按公元前312年断言原书只有一个纪年。

**最早名称使用**：汉中市地方志2025文章称战国楚置汉中郡、秦前312年取而改置；2026文章又称前451年秦在今汉中筑城并因此命名。两种说法可能分别指城、区域和郡，但目前尚缺同时代文书，不能把“某地筑城”“首次出现汉中这个词”“楚郡建置”“秦郡改置”直接等同。

**郡治与现代同名城市**：早期汉中郡治有今丹江口、安康等解释，现代汉中市并不是所有战国秦汉汉中郡治的自然唯一锚点。

## 3. 张家山汉简《二年律令·秩律》提供反证：同名不等于同地

《二年律令》来自湖北江陵张家山247号汉墓，现代研究一般围绕吕后二年（前186）讨论成书／抄写时点。但马孟龙研究指出《秩律》内反映的朝廷直辖政区名录可能对应吕后元年左右；**简册的书写时间与其反映行政状态的时间并不必然一致**。

潘国立《张家山汉简〈二年律令·秩律〉地名考释三则》，《历史地理研究》2025年45(4):129—132，2025-11-20出版、2026-01-19上线。其官方期刊摘要明确提出：
- 简456里河南郡“梁县”为东部的战国魏都大梁，**与《汉书·地理志》河南郡梁县异地同名**；
- “岐县”位于河南郡东部，作者认为对应今河南通许以北的西城村遗址；
- “卷县”原城址在今原阳县祝楼一带，后移治衡雍；省县之后，把衡雍误当卷县始置县址是后世地望误配。

## 4. 比较与新类型建议

| 模式 | 例子 | 证据等级与限制 |
|---|---|---|
| 河川/山地名 → 政区名 | 汉中；三川传统释源 | 文献直接见解释，但命名最初现场未获得 |
| 同区域改行政名称 | 秦三川郡 → 汉河南郡 | 《汉书》明确记述，辖境是否全同另证 |
| 方位词独立复用 | 历史上不同“河南” | 谭其骧等古今多区用法整理；逐例研究实际参照区域 |
| 同名异地 | 汉初简456“梁县” vs 汉书河南郡梁县 | 潘国立2025官方摘要的研究主张，原简未核 |
| 县名保留而县治迁移 | “卷县”与衡雍 | 潘国立2025摘要提出，迁治的证据仍待全文和原简核验 |
| 水名→政治封号→国号 | 汉水、汉中、汉王、汉朝 | 史籍可追政治名称关联，但不能直推民族形成 |
| 政区列表承载政治空间分类 | 《秩律》与《汉书》排序比较 | 马孟龙2024论文书目及研究报告；须读全文再做系统结论 |

我们需要的不是“中文地名全部有某种规律”，而是用可追踪材料检验名称的功能、历史对象和行政机制。

## 5. 新的研究主张（均为待测试）
- **QH2-H01**：自然参照关系可能长期保留词义，但地名指涉区域和行政组织并不因此不变。
- **QH2-H02**：制度化可使旧山川名成为多层行政名称，但也可能诱发异地同名、同地改名、迁治等混淆。
- **QH2-H03**：因文书排序和县邑隶属不同，不能把文献中的名单顺序天然当作物理空间线路或等同县级实体。
- **QH2-H04**：从水名到王朝号的社会扩展不能直接推导民族身份的一元起源。
- **QH2-H05**：地名是否能够延续，受政权继承、文书系统、人口使用、历史记忆等共同影响；现阶段缺全国数据，因果优先级未证。
