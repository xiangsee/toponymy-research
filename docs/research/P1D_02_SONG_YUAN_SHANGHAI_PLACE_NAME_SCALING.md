# P1-D 研究札记02｜一个地名如何上升为城市名称：上海浦、上海务、上海镇与上海县

**日期**：2026-11-22｜**阶段**：P1 中国地名起源与历史研究，衔接隋唐州郡名称制度后推进唐宋元城乡与商业地名。  
**状态**：MIXED_SOURCE_VERIFIED，直接核对《元史·世祖纪》《元史·地理志》与明弘治《上海志》公开古籍文本，另核上海民政委托复旦历史地理研究、复旦CHGIS、青龙镇遗址考古官方说明。**《宋会要辑稿》具体酒务账目原页、郏亶《水利》文献原稿、全部早期港口设施考古尚未直接完成原件校勘。**

## 核心结论与限定
- 可以证明“上海”从宋代已出现于酒税机构名称，到南宋的港镇名称，再到元朝被用于县级行政区；其间税收、运输、海商活动和人口规模是需要研究的历史机制。
- **不能把上海浦→上海务→上海镇→上海县写成四次已核实的连续命名法令**。名称初创和“浦”“务”究竟哪个先取得“上海”二字，文献并不充分；同一名字在不同场景并行使用。
- 不能把“千年上海”和“1843开埠后小渔村才变都市”混为一事。华亭县名与上海较早的聚落、港口、税务名称不同。
- 研究目标不是复述上海发展史，而是找到**自然/聚落称谓—财政识别—市场交易—行政边界**之间能够通过史料检验的联系。

## 一、不同历史名称的证据阶梯

| 名称角色 | 文献节点与证据 | 当前能证明 | 不能直接推出 |
|---|---|---|---|
| 上海浦（地理水道） | 明万历《上海县志》引《永乐大典》所保存的郏亶宋代《水利》材料，提“上海、下海二浦”；傅林祥2023研究整理了“上海浦”和“上海务”的不同先后说 | 宋代水道名可通过后世文献引录追溯，有可核文本传承链 | 水道名一定先于同名聚落/酒务，以及今黄浦江全段就是古上海浦 |
| 上海务（酒税机构） | 上海市民政局委托傅林祥2023研究据《宋会要辑稿》税额/旧额推到**不晚于1023年**；通行《上海通志》等另记1077年设置。复旦王启元2023也指出“酒务”有多处宋代记录 | 至宋代已存在官方榷酒机构与“上海”名的对应，至少1077年资料与更早额度回溯可研究 | **1023年有一份“创设上海务”的直接诏令已被本项目核到**；“1077创设”是唯一无争议时间 |
| 上海市／上海镇（港镇） | 明弘治《上海志》称宋末蕃商辐辏、镇有市舶提举司和榷货场；上海民政2023研究记1269年市舶分司官员董楷兴建街坊等 | 商业、航运管理与镇区发展相互关联；“上海”已由局部机构名扩至聚落/镇 | 任何市场、口岸或酒务出现便自动设行政镇，或每座成功港镇最终都建县 |
| 上海县（元行政县） | 《元史·地理志》记**至元二十七年1290**；《元史·世祖纪》至元二十八年七月己未记“分华亭之上海为县”即**1291**；弘治《上海志》记**至元二十九年1292**。复旦CHGIS县治始于1292；地方史研究区分奏议、批准、运行 | “上海”作为正式县名及其隶松江府有多类原始/后出文献；差异可能对应行政设县多个环节 | 已经找到证明1290仅为奏议、1291仅为批准、1292仅为始设的全部独立原始档案，或三种记载可以简单选择其一把其余判错 |

### 宋代“1023”的特殊核验边界
上海民政2023年文章使用“最晚至天圣元年（1023），华亭县境内已经有上海务”，其推断与《宋会要辑稿》关于旧额来源年份及酒务记录有关。**本项目尚未直接核看《宋会要辑稿·食货》原卷对应条及各表的原版行文，因此标为 SECONDARY_RETROSPECTIVE_DATING，而不是 DIRECT_FOUNDING_EDICT_1023。** 1077年也不宜不加辨析地写为“创设年”，因为更早酒务线索存在。

### 上海浦与上海务谁先？
2023年傅林祥专门指出，浦名和聚落名称哪个先形成难以证实。弘治《上海志》的“海之上洋”是明代释名；万历《上海县志》引北宋郏亶《水利》，从上海/下海两浦推断县名与水道有关。必须区分三层：
1. 宋人可能用过的水道名称；
2. 明代县志所保存并解释的宋代引文；
3. 最初命名者实际采用名称的动机（尚未查到现场材料）。

## 二、1290／1291／1292三种建县时间并非可以随便统一

1. **1290（至元二十七年）**：元史卷62《地理志》写“以户口繁多，置上海县”，属于元末明初编纂的后出行政沿革归纳。
2. **1291（至元二十八年）**：元史卷16《世祖纪》记七月己未“分华亭之上海为县，松江府隶行省”，更接近具体朝廷决定的记载；上海长宁区政府提供1291年8月19日的日历对应。
3. **1292（至元二十九年）**：明弘治《上海志》“以民物繁庶，始割东北五乡立县于镇”。元代唐时措《公署记》被后世县志引用，言主簿开始理事与划出五乡二十六保。复旦CHGIS采用1292为上海县节点起始。

**本项目推断**：这可能是提出议案/正式批准/县署与乡保实际组织依次实施，具有解释力；不过如果将1290作为“已查明具体提案日期”也需要查原奏议，不能凭后代和现代讲述把猜想升为原档事实。

## 三、反例：青龙镇比上海镇更早繁华，却没有以“青龙”为名演变成现代市名

上海博物馆2016公开考古说明：
- 青龙镇遗址在今青浦区白鹤镇一带，唐天宝年间已有镇名，唐宋是重要贸易港口。
- 1113年青龙镇所在华亭县有市舶务；1131年青龙镇单设市舶务。2010—2016发掘发现唐宋建筑、水井、灶、铸造作坊及大量瓷器，展示海运贸易证据。
- 吴淞江水系变化导致青龙港口功能下降，而名称后来在地名、遗址与文化保护轨道继续存续。
- 官方2019年以来的全国重点文物保护和2025年地方政府办理提案，进一步说明青龙镇的文化名称存续与商业港口功能存续是两回事。

**研究推论（非已证单因果）**：地名从港镇提升为县级或更高级行政名，需要人口、税收、交通、政治决策和行政管理成本等因素共同起作用；**港口规模与贸易繁荣既不是必然必要条件，也不是单独充分条件**。青龙镇是检验“经济发达必成县名/城市名”的负例，但不能据此说青龙衰落的唯一原因一定是吴淞江淤积，也不能把两港视为同一时期单纯的胜败零和替代。

## 四、需要添加到地名学分类中的独立机制

- `HYDRONYM_OR_TOPONYM_SHARED_FORM`：河道名、聚落名与税务机构名同形，但先后未必可知；
- `FISCAL_OFFICE_AS_NAME_ANCHOR`：政府酒税、市场税等机构固定使用已有地方称谓；
- `TRADE_SETTLEMENT_CONSOLIDATION`：税务和航运交易促成镇级市场集聚；
- `MARKET_TO_COUNTY_ADMIN`：已有镇名用于新正式县，需单列建县决定和实际县署开始运行；
- `HARBOUR_ECONOMIC_DECLINE_WITH_NAME_SURVIVAL`：港口活动衰退，名称转入地方和文保记忆（青龙）；
- `CONFLICTING_INSTITUTIONAL_DATES`：不同史书的1290/1291/1292可能指奏议、批准、实施三个事件，也可能存在记述差错，**不得事后强行归因而无证据**。

## 五、两种空间位置必须分开

上海务和老城厢大致属于今天上海市黄浦区旧城南部，但复旦王启元2023介绍钟翀对务址的研究提出小东门健康苑一带的候选位置；**目前尚未由本项目考古发掘独立确址**。青龙镇遗址在今青浦区白鹤镇，由上海博物馆与青浦区政府有考古确认。两者是不同港镇发展路径，不应凭现代城区认定宋代所有“上海”均为今外滩具体坐标。

## 六、Claim Lifecycle 与下轮核验

- `affected_claim`: “宋代上海务建立于1077年”及“1023年已有上海务”，分别修正为**1077是有证年份，1023是基于更早酒税额度资料的学术回推，建置初年不确定**。
- `affected_claim`: “上海得名必先有浦、再有务、再有镇”，改为**多功能共存；浦与聚落先后未证**。
- `affected_claim`: “上海县1292年设立”，拆分**1290《地理志》记载、1291《世祖纪》诏决、1292县署/县志说**；继续核三者各自的时间含义。
- `affected_claim`: “唐宋港口兴盛必然产生现代市名”，青龙镇为强反例线索。

**下一条关键证据**：
1. 直接核《宋会要辑稿》食货卷相关“上海务”各处原文、账目时段，建立1023与1077的文献传承卡；
2. 读《元史·世祖纪》七月己未和《地理志》原版、元代唐时措《上海公署记》经明志引文，按事件类型记录1290、1291、1292；
3. 查郏亶《水利书》在《永乐大典》/《上海县志》中的原始引文与文字异本；
4. 以上海镇与青龙镇为一组经济兴衰/名称升格的对照，取得考古实物及税收数据，可证因果后再提升判断；
5. **警惕数据选择偏差**：不得只用成功变成现代大都市的上海来解释商业地名的所有演化。
