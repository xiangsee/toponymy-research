## 二、两个不可混淆的“同一性”

### A. 物证同一性（publication identity / physical object identity）

同一甲骨实物 → 不同著录书中不同的著录号；碎片后来可能缀合为一个更大的实物单元，同一编号亦可能包含不同正反面及重见号。

- 最小对象：`physical_object_id`（如确定性不足则为 `object_id_provisional`）。
- 一一记录 `edition/series`、`catalog_number`、`side`、`rubbing/photo`、`holding_institution`。
- `ALIAS_CONFIRMED` 必须基于可靠著录对照/图版比对；未实际检索时只能 `LOOKUP_PENDING`。
- 缀合需说明原片及现代拼合证据；勿将学术推测的拼合直接作原始物证事实。

### B. 历史名称指称同一性（name type / historical referent identity）

不同甲骨或传世文献写了相同字形“目”“亡终”，只能说明 `SAME_FORM`，不能说明它们指向同一族群/同一地理地点。

- 原文出现一次字为 `attestation_id`（语境所在证据）。
- 字形规范化记录在 `name_form_id`，保留古文形、通假、隶释差异。
- 所指对象另建 `historical_referent_id`：人物、族群、国、山、聚落、县、田猎地等。
- “两个attestation是否指向同一referent”是一条**有证据和异说的关系命题**，不得在导入时自动合并。

**硬原则**：同物异号与同名异物是两个方向的识别问题；解决前者，并不会自动解决后者。

## 四、“无终”的独立分层与新发现的断代差异

- 石蝶《商代中期有铭青铜器探讨》，《故宫博物院院刊》2006年第4期，将无终戈定为**商代中期**（《集成》10881，1965绥德出土）；相关引文将裘锡圭释“亡终”与《合集》4307反联系。
- 徐驳2024年介绍金文合文的文章称它是**商晚期器**，并用图展示《集成》10881的“亡终”合文字。该文不是专业断代论文，不能与石蝶权威性等量齐观，但足以把分期差异加入核验队列。
- 日本 CiNii 文献目录明确《殷周金文集成》第17册收录10591—11407号戈戟铭文，第13册收录7313—8310号爵角铭文，因此可定位 **10881→第17册、7494→第13册**。**这只证明书目所在卷次，不等于已读取该卷原拓。**

来源：石蝶故宫院刊第41—42页：https://www.dpm.org.cn/Uploads/pdf/5059/T00041_00.pdf ，https://www.dpm.org.cn/Uploads/pdf/5059/T00042_00.pdf；徐驳：https://www.sohu.com/a/751209817_121843268；CiNii：https://ci.nii.ac.jp/ncid/BN04916392

“无终”历史来源的四种材料仍分别保留：
1. 商代青铜戈族氏铭文及甲骨活动线索；
2. 《左传》无终子嘉父；
3. 《汉书》右北平郡无终县与故无终子国的追述；
4. 唐李贤注《后汉书》“山名→国号→县名”的来源解释。

这四类材料跨越不同时代与文本层次，目前**没有**可直接证明商代陕北器物、春秋政治集团、汉县位置三者构成一条不间断迁徙链的材料。唐人释源与铜戈族徽释读所表达的“名称先后”不是同一类命题。

## 五、引入“不确定性不降级”的研究约束

国家图书馆专家陈红彦、赵爱学（2023）公开报告：他们对以往甲骨缀合的504组实施实物核验，发现39组误缀。另有因不清晰拓片引发的释文差错。来源：https://www.nopss.gov.cn/n1/2023/1115/c448861-40118773.html

由此可知，**原始证据也有文物、拓片、释字、时间和拼合多个版本**。不能把表格“数据库已匹配”作为最终学术证据。每种断言应保留：支持证据、竞争释读、缺失的原片、验证动作、更新日期。
