## P1-B：20—30个高质量个案
优先按：地名专用字、普通词→地名、旧名承继、词源争议、跨语言名称、同名异地、地域扩张、政治纪念等分层抽样。
**验收不以例数为唯一标准**：每个完成的个案需具备时间线、至少一项可复查来源、竞争解释、未决问题，并将断言与来源对应。

## P1-C：地名语义与样本比较
- [ ] 确认“古字义／整词古义／现代整词义”的区别
- [ ] 查询古今辞书与语料，定义“地名专用”的时间与语种限定
- [ ] 多语言音译/意译另设来源与转写核验
- [ ] 抽样验证分类边界与不适用例

## P1-D：数据质量与公开研究报告
- [ ] 对分类标签、证据等级与历史事件结构进行独立复核
- [ ] 发布“确定事实／争议解释／数据推断／研究假说”分层报告
- [ ] 讨论扩大样本的合法数据渠道与抽样偏误
- [ ] P1复盘后决定是否达到 P2 启动条件
