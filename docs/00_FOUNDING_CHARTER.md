# 研究章程 / Founding Charter
**版本**：v0.1（2026-11-21）  
**范围**：长期、公开的地名起源与制度史研究。  
**当前工作阶段**：中国地名史。

## 研究初心

从中国地名的真实历史出发，考察名称如何产生、被继承、改写、迁移与遗忘。首先建立可靠的地名学和历史地理基础；之后开展国外比较；最后才研究商标法中地名规则的历史来源与制度适应性。

## 核心问题

1. 在商周以来的历史文献、考古和语言资料中，地名起源可以归纳成哪些命名机制？
2. 哪些词主要专用于地名，哪些词在普通语言与地名之间有双重用途？这些状态是否随时间变化？
3. 一个名称在地理实体、族群、政治共同体、行政区划、文化和产业之间如何流动？
4. 地名如何随迁徙、政权、文字、行政区划及全球交往而变化？
5. 哪些所谓“历史由来”存在争议、后世附会或证据不可得的问题？

## 必须遵守的边界

- 不先用商标法“其他含义”定义来划分中国古代地名。
- 词义、词源、语音、文字、地理指称和行政建置必须单独核验。
- 同名异地、一地多名、同一名称多重历史对象分别记录；不以现代地图回填古代地望。
- 不预设中国与外国地名起源“完全不同”，留待第二阶段比较。
- 不预设地名进入商标法的最初来源和合理性，留待第三阶段史料研究。
- 不把争议学说转成唯一结论；留存反证、异说和资料缺口。
- 不大规模复制第三方受版权保护文本、未获许可的数据库内容或私人资料。
- 科学结论与方法、数据推断及研究建议分别标注。

## 预期产出

- 可追溯的中国地名源流案例库和证据目录。
- 起源机制×词义状态×历史事件的多轴分类系统。
- 典型地名的可复核历史档案、争议图谱和对照案例。
- 在有合法数据条件下进行分层抽样，研究类型分布而非凭印象推断全国比例。
- 中国阶段结题复盘后，再开启比较地名学；最终产出地名与商标制度史研究。

## 工作规范

每项具体断言登记：claim_id、时间/地域范围、原始来源、证据类型、支持/反证、当前状态、下一核验动作。关键疑义必须公开保留，尤其是汉字望文生义、传说时代与文献记载时间混淆、古今地望错置。

本仓库是公开研究记录；研究内容未经逐项核验时不可视为可靠结论。
