## 引文层级与版本问题

1. 班固《汉书》正文、应劭等前人注、颜师古唐注及后世整理者注，必须在每条断言中分别注明，不得一概叫“《汉书》认为”。
2. 《水经注》卷二引《汉官》的郡名六类，可在《太平御览》对应引文找到归名为应劭《汉官仪》的线索；尚须逐字核对版本异文。
3. 《元和郡县图志》的唐代原图后来佚失，四库本又有缺卷和后代整理。不能以一个现代网页或清代本推定唐原本完整无误。
4. CHGIS用于验证政区名称、地点、时间及辖域变化，不适合直接证明语义来源。
5. 已公开链接的第三方作品不等于可以整体再发布；这里只放元数据、来源链接与原创摘要。
