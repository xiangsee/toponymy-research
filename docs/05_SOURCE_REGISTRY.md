## 文献使用规范
- 对“地名何时形成”，不得仅引用现代网页的一个日期；须区分最早存世记载与推定的形成时间。
- “官方资料”在当代建置事实方面较强，在上古词源方面不必然优于早期文献或语言学论文。
- 来源未取得原文时，仅记录线索，不转述为已证结论。
- 外部链接可能变动，应在核验记录附访问日期、作者、文题、出版信息和存档线索。
- 原书全文和受版权保护PDF不直接上传。
