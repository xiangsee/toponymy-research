## 引文层级与版本问题

1. 班固《汉书》正文、应劭等前人注、颜师古唐注及后世整理者注，必须在每条断言中分别注明，不得一概叫“《汉书》认为”。
2. 《水经注》卷二引《汉官》的郡名六类，可在《太平御览》对应引文找到归名为应劭《汉官仪》的线索；尚须逐字核对版本异文。
3. 《元和郡县图志》的唐代原图后来佚失，四库本又有缺卷和后代整理。不能以一个现代网页或清代本推定唐原本完整无误。
4. CHGIS用于验证政区名称、地点、时间及辖域变化，不适合直接证明语义来源。
5. 已公开链接的第三方作品不等于可以整体再发布；这里只放元数据、来源链接与原创摘要。

- **陶瓷考古反证 SRC-142**：吴红云、邵建春2025《中国陶瓷》第6期《北宋“景德年制”瓷器款识新考》，**本轮只读知网官方摘要，尚未核论文全文和湖田窑发掘报告**。作者质疑清人把明年号款倒投宋代，但论文同时支持年号赐名的传统说，两者证据不同，不能互相自动证明。
- **唐代山名设州 SRC-144/145**：《旧唐书》40和《新唐书》41明州条取四明山名、738置州、742改余姚郡、758复州。后出史书较明确，但未找到齐澣奏请原件。
- **明州港市传播 SRC-146—149**：宁波城市历史821、898建城，宁波考古采访和广州博物馆研究992/999市舶制度、宁波中国港口博物馆港口交流史。属于“早已存在的明州名因港贸扩大使用”，不是“738因宋代贸易而得名”。
- **宋庆元府 SRC-150/151/156**：《宋史·宁宗本纪》记1194绍熙五年十一月升府并命次年改元；清《鄞县志》同记1194。某些现代沿革以1195纪年；行政实际生效与府官活动需查宋代原始案卷。
- **明宁波府 SRC-152—155**：《明史》及《明一统志》1381年二月改宁波；明代《大明一统名胜志》及宁波官方史述避“明”王朝国号与“海定则波宁”的说法是**命名动机与后代故事**，需与正史明确更名年份分开。

## 补充考古原始资料线索（SRC-157—158）

- **SRC-157**：[故宫博物院景德镇窑青白釉双鱼碗藏品](https://www.dpm.org.cn/collection/ceramic/227243.html)：故宫藏品号故00143128；所附背景说明提及江西九江宋咸平三年1000年纪年墓早期青白瓷钵，**纪年墓出土不等于生产日，产地亦待原发掘报告核证**。
