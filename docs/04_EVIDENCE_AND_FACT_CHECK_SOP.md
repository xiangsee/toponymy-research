# 地名源流证据 SOP v0.1

## 1. 一个断言一张证据卡

必填：claim_id、原文断言、地点/对象唯一键、限定时期、最早现存来源、检索时间、支持材料、竞争解释、反证、核验状态、下一核验动作。若无法判断词源，写“未知”，不猜测。

## 2. 证据层级（用于描述来源性质，不自动决定结论）

- **E1** 同时代原始记录：甲骨、金文、简牍、碑刻、文书等，可核的年代与释读。
- **E2** 接近当时的传世文献、历史档案、行政命名/更名原始公文。
- **E3** 后世正史地理志、地方志、古地图、权威工具书、整理资料。
- **E4** 有出处、明确论证方法的现代学术研究。
- **E5** 官网页面、地方传说、旅游说明、媒体转述和百科梳理：通常只提供研究线索或现代官方说法。

证据相互独立性与质量需个案判断。E4学术文章使用E1材料可形成较强论证，但不能用发表场所替代原文核验；现代政府网页对当代建置事实通常有价值，但对上古词源不一定优于出土资料。

## 3. 词源核验硬规则

- 历史记载中“最早见于”需限定检索语料，不能无限断言“最早出现”。
- 汉字望文生义不足以证明历史词源。
- 少数民族语言与方言材料应记原文形式、音标/拉丁转写、年代、学者译释，不凭现代汉字拆字。
- 地理实体、行政单位和名称实体分离，行政区建置日期不等于词源日期。
- 记录异说来源与强弱理由，允许DISPUTED/UNKNOWN长期存在。
- 对各地旅游宣传性“某帝王赐名”“某传说命名”保留严谨求证。
- 任何声称“只作地名”，须说明所考察的时间、语种、词典、语料与字词层级。

## 4. Claim Lifecycle

状态：PROPOSED → EVIDENCE_FOUND → CHECKED → DISPUTED/REVISED → STABLE / REJECTED。
每次变更记录：
- affected_claim：影响哪个旧判断
- impact_type：支持 / 扩展 / 修正 / 反驳
- verification_next：下一条决定性证据是什么

STABLE不等于永久真理；出现新材料继续复核。

## 5. 工作流程

(1) 明确地名对象与研究问题 → (2) 搜索早期原始文献与学术成果 → (3) 建独立来源卡 → (4) 对照地望和行政沿革 → (5) 检查语音、字形、含义 → (6) 收集反例/异说 → (7) 标记可用结论与疑点 → (8) 更新数据和版本记录。

## 6. 公共仓库的版权与隐私

第三方论文、专业数据库和PDF原件只登记元数据与来源链接；没有授权不上传全文。公有源资料也不能未经核实推定皆可再许可。不发布个人私人信息、商业项目内部资料及聊天记录。
