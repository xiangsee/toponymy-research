# 地名的历史、语言与制度｜Toponymy Research

> 《详见》长期公开研究项目。当前阶段：**中国地名的起源、演变与词义**。
>
> 地名既是指认空间的语言工具，也记录人口、族群、政治制度、迁徙和文化传播。我们先把地名史研究清楚，再进入世界比较，最后考察地名为何以及如何进入商标制度。**不以今天的商标法分类倒推古代地名史。**

## 研究顺序（阶段门）

1. **P1 中国地名史（进行中）**：从商周、秦汉到近现代，研究起源、词义、历史地理指称、命名和更名机制，形成可证伪的分类及典型案例。
2. **P2 世界地名比较（未启动）**：在中国阶段基本完成后，分别研究不同语言、宗教、殖民及国家形成背景中的地名；不预设“国外地名完全不同”。
3. **P3 地名与商标制度史（未启动）**：核查地名禁注规则的国际与中国法制史、移植过程、制度目的及现代条件的变化；不预设移植链条或废止结论。

## 第一阶段的核心区分

| 维度 | 核心问题 |
| --- | --- |
| 名称史 | 一个名称在何时、何种材料中第一次**可证实**出现？ |
| 地域史 | 名称当时指向哪里，与今天指向的空间是否相同？ |
| 建置史 | 何时成为郡、县、州、府、市等正式行政名称？ |
| 语义史 | 名称来源、普通词义、专名功能及语言使用是否变化？ |
| 证据史 | 哪些结论来自同时代文字，哪些只是后世传说或推测？ |

**形成时间 ≠ 最早存世记载时间 ≠ 行政建置时间。**  
**单字古义 ≠ 整体地名词义。**  
**名称相同 ≠ 地点相同。**
