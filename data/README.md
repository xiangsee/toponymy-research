# 数据文件 / Data

- `seed_cases.csv`：30个**待研究的问题样本**，仅为任务登记。任何“候选机制”均非最终判断；全部初始状态 QUESTION_ONLY。
- `source_registry.csv`：公开来源的元数据与定位状态。URL_LOCATED仅表示已定位网址，不表示所有具体论断已完成全文核验。
- `toponym_case.schema.json`：预备采用的个案JSON字段约束，**不代替学术判断**。

## 字段原则
一行/一对象可以是同名地名中的特定一地，不能按字符串合并所有地理实体。“朝阳（辽宁）”与“朝阳（北京）”分别有独立case_id；同名关系另用证据记录。

至少保留三个不同时间：名称的推定形成日期、最早可证记载日期、行政正式采用日期。缺失写null或UNKNOWN，不填假想日期。

数据尚未经全国抽样，不可据此推断中国地名类型比例。
