# C053｜青龙镇：繁盛的唐宋港口为何没有成为今天“上海市”的主名？

**研究状态**：MUSEUM_ARCHAEOLOGY_VERIFIED / TRADE_DECLINE_HYPOTHESIS_SUPPORTED / ORIGINAL_NAMING_ETYM_UNPROVEN
**日期**：2026-11-22

## 研究价值：作为“经济繁荣必使地名行政升格”的反例

青龙镇遗址位于今上海市青浦区白鹤镇一带。上海博物馆2016年正式考古新闻、青浦区政府2020年遗址资料、青浦博物馆史料相互支持：唐天宝年间青龙镇已成为重要港口节点，宋代海商繁盛；青龙镇地望经考古确认，2010—2016考古出土水井、建筑基址、灶、作坊、大量外销瓷，2019年成为全国重点文物保护单位。

## 分层时间轴
- **唐天宝年间（742—755）**：博物馆文献回顾称该时段设镇，青浦博物馆称746年沿海军镇。具体最早建镇、镇名由来及直接唐代公文尚未核定。
- **宋1113**：据上海博物馆，青龙镇所属秀州华亭县设有市舶务；**不能自动等同青龙镇当年有独立市舶机构**。
- **宋1131**：上海博物馆称青龙镇单设市舶务，显示贸易管理机构名称和港镇位置有关。
- **南宋后期**：青浦博物馆、上海博物馆将青龙镇港口功能衰落与吴淞江淤塞、水系变化相联系；这一因果仍需水文学、河道与贸易量同步证据检验。
- **明嘉靖1542及其后**：青浦博物馆称青浦设县早期一度以青龙镇为县治，后来治所迁移，旧港名称和实体并未因此完全从地方文化中消失。
- **2019以后**：以全国重点文物保护单位等方式保存青龙镇遗址和古港名称，这属于文化遗产使用渠道而非持续存在的唐宋港务行政功能。

## 与上海镇对照的限制
- 青龙镇比上海镇早有繁盛外贸港的直接考古证据，地位高却未以“青龙”成为今天的市级主名；可作为**不充分条件的反例**。
- 上海县从一个宋代名为“上海”的酒务/港镇地区以元行政命令设立，是不同制度路径；不应把“青龙→上海”画成具有确定日期的单向替代，亦不应宣称青龙港衰落的唯一原因就是河道淤塞。
- **名称寿命与经济功能寿命不同**：青龙商业港功能衰退，名称仍可经史料、古迹、博物馆和文保制度延续。

## 需要下一步做的事
1. 追查唐746年设军镇的真正历史原始记载及“青龙”二字原始词源。
2. 对读上海博物馆正式考古报告与《故宫博物院院刊》2025年王建文出土瓷器研究（PDF正文尚未独立读完），确定港市时段和贸易规模证据。
3. 查吴淞江古河道变迁研究及航运税额，避免用“青龙兴盛—上海崛起”的时间先后推断唯一因果。
4. 查明代青浦初县治及后迁确切年月，考察“镇名存、县治走”的历史连续性。
5. 与上海县[C008](C008_SHANGHAI_FISCAL_PORT_COUNTY.md)对照，看何种条件使港镇名称进入县级行政身份。
