# C042｜河南：一种方位词形，多个独立的历史地理对象

**状态**：HISTORICAL_SECONDARY_SYNTHESIS / MULTI_REFERENT_NOT_YET_GEOLOCATED（2026-11-21）。

这是一个**区域称谓研究对象**，与C041“具体行政河南郡”不同；不要把所有“河南”归到一个地理实体ID。

谭其骧等整理的历史叙述涉及：战国韩魏宋等国黄河南部区域；秦汉河套某些“河南”区域用法；南北朝吐谷浑相关的青海黄河以南地区；洛阳周边的河南县/郡；唐河南道、元河南江北行省、明清河南省。

不同名称可能因“相对于黄河的南侧”**独立形成同样字面表达**，也可能沿用旧政区。必须按不同时代、空间范围和语言/文书语境逐条编码。

**不能说**：现代河南省与所有历代“河南”都指向相同空间；黄河河道变迁必然导致行政区划实时同步改变；所有河南名称来自一个唯一的最初古地名。
