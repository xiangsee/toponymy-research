# C034｜甲骨卜辞中的「方」：它是专有国名吗？

**研究状态**：ABSTRACT_ONLY / PRIMARY_ORACLE_IMAGE_PENDING

## 研究对象
不是现代叫“方”的某个地区，而是甲骨卜辞中一个文字（token）的专名属性问题。**尚不能确定独立方国实体**。

## 证据线索
李林《殷卜辞所谓“方方”献疑》，《文献》2025年第1期，第4页起。国家图书馆《文献》2025年第1期目录与摘要介绍：
- 一项旧说将《殷虚文字乙编》第107片的“方方”连读作为独立方国“方”的论据。
- 作者据史语所最新公开高清彩照重新释读，指出旧“方方”连读有误。
- 作者提出“方”可能是某方国的简称，或泛指敌对方国/带有方位指示的泛称。

## 不能据此说
- 不能在未读全文、未看高清照片情况下，独立宣布已“证实”旧说绝对错误；
- 不能以一个“方”字就确定一个独立方国；
- 也不能据一篇摘要推翻所有甲骨卜辞中出现的相关地名。

## 研究方法收益
建一个**词形→句法→语境→是否专名→是否地理实体→地望**的分阶段管线，允许只在前两个阶段确定，而后续未定。若词法判别尚未过关，禁止自动映射现代地图坐标。
