# C035 目：同字多功能——甲骨与族氏铭文

日期：2026-11-21。状态：SPECIALIST_TRANSCRIPT_LOCATED / ORIGINAL_RUBBING_PENDING。

| 用途 | 著录 | 目前依据 |
|---|---|---|
| 眼睛 | 《合集》165正及《集》456正 | 港中大字库、钱唯真 |
| 观察／侦察动词 | 《合集》6195；钱唯真另举6194 | 语法功能优先，编号待校 |
| 人名、子目 | 《合集》14034、20173等 | 赵鹏《读契札记一则》 |
| 田猎地 | 《合集》29285、29286、33367 | 赵鹏、喻遂生；例如“王其田目” |
| 族氏称号 | 《殷周金文集成》7494“目爵” | 港中大字库、汉典，原拓待校 |

结论：**同一字形可以表示普通词或多类专名，不代表原始词源和历史承继方向已证。** 不得把字形的“眼睛”本义直接解释为族氏或地名的命名原因，也不能据金文族徽和甲骨田猎地同名就认定一方派生自另一方。

关注反证：不同卜辞中的“目”可能是不同人物或地点，且当某处“目”是侦察动词时不应误建地名实体。
