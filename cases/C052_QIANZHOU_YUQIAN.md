# C052｜潜州—於潜县：唐初短命州的撤销与县名存续

**状态**：OLD_TANG_SHU_TEXT_READ / COUNTY_BOUNDARY_UNVERIFIED
**记录日期**：2026-11-22

《旧唐书》卷40杭州属县“於潜”条：“武德七年，置潜州，领於潜、临水二县。八年，废潜州及临水县，於潜还杭州。”

由此可以记录两条不等价的地名命运：
- 624—625年潜州行政建置短期存在，后撤销；
- 於潜县名称继续在杭州政区体系使用。

**不应推论**：潜州撤销使“潜”“於潜”作为词形完全退出地方社会；唐初潜州就是侨州；当时於潜县辖境和今日地名地望完全相同。
