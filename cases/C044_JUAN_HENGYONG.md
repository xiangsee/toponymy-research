# C044｜卷县与衡雍：县治迁移如何扭曲地名源流

**状态**：PEER_REVIEWED_ABSTRACT_ONLY / ORIGINAL_SLIP_456_PENDING（2026-11-21）。

潘国立2025《张家山汉简〈二年律令·秩律〉地名考释三则》官方期刊摘要提出：卷县早期县城在今河南原阳县祝楼乡东、西圈村一带，后迁治衡雍。因卷县后来被省，后世把衡雍的位置误认为卷县自设置以来的县址。

这是一项需要**独立审查原论文和原简**的地望考释，并非本项目已经确证的“卷县确切初建地点”。

本案例压力测试以下三个对象：
- 县名“卷”的语词和制度来源；
- 先后两个县治的实体位置及迁移事件；
- 行政县“卷”的建置与撤并，是否与衡雍城名混同。

**禁止逻辑**：县名一样且后期行政县治在衡雍 ⇒ 县名自开始就指衡雍。

主要来源：潘国立，2025，《历史地理研究》45(4):129—132，DOI https://doi.org/10.20166/j.issn.2096-6822.L20230227 。

下一步按《秩律》简456及各阶段县治地望原始证据逐条核；另与《汉书·地理志》“卷”县条比对。
