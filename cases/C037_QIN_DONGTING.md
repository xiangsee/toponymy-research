# C037 秦洞庭郡：出土秦简如何改写传世政区认识

**记录时间**：2026-11-21。**状态**：ORIGINAL_EXHIBIT_TEXT_CONFIRMED / COUNTY_LIST_SCHOLARLY_RECONSTRUCTION。不是2026年完成了全部简牍原图核查。

## 史料
- 里耶出土“迁陵 洞庭郡”简（国博2019相关展览资料、深圳博物馆“迁陵洞庭郡简”），能确证秦行政地名。
- 2002年里耶一号井及2005年护城壕相关秦代档案：国家档案局2025年公布的资料计3.8万余枚，核心纪年前222—前208。
- 《史记·秦始皇本纪》“分天下为三十六郡”是统一初期叙述，不代表最终秦郡名录；洞庭郡新见说明需动态研究。
- 游逸飞2015年论文以8-159、9-712+9-758等重建辖县与邮书网络，部分县隶属仅为推论。见 **表五 PDF第13页（期刊第41页）**。
- 复旦CHGIS“武陵郡”仅代表西汉某时段的历史地理重建，不等于秦洞庭郡的全部边界。

## 关键不确定性
1. “洞庭”作为郡名是否直接取自洞庭湖，需核战国及楚秦更早地理名证据。
2. 郡治位置及历次迁移，研究者不同主张，需要简牍文书线路支撑。
3. 秦洞庭郡→汉武陵郡的行政演变，并非已确证一对一更名、辖区保持不变。
4. 2026年有“里耶楚秦合简”论证，涉及少量文书是否形成于楚治，需要按简号复核。
